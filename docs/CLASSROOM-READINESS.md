# 비회원 수업 접속 및 사용성 점검

2026-11-17 기준. 비회원은 가입 정원과 관계없이 각자의 브라우저 세션으로 이용한다. 기록은 시작일부터 7일간 접근할 수 있으며 쿠키 삭제 또는 비회원 종료 시 다시 찾을 수 없다. 가입하거나 기존 계정으로 로그인하면 기록을 이어갈 수 있다.

## 이번 보완

- 비회원 시작 버튼과 계정 로그인 영역을 구분하고 입력 도움말을 입력란과 연결했다.
- 서버가 HTML 오류를 반환해도 기술적인 JSON 오류 대신 재시도 방법을 안내한다.
- 개인정보 처리 용어를 마스킹으로 통일하고 발화자 대신 보낸 사람으로 표시한다.
- 이메일 주소를 생략한 경우 다음 단계에서 보낸 사람을 확인해야 함을 입력란 아래에 설명한다.

## 확인한 범위

- 자동 테스트 289개, JavaScript 구문 검사 152개 통과.
- 실제 Chrome 1440px·390px: 가입 없이 진입, 이메일 등록·분석, 영어 초안, 새 답변 비교, 새로고침, 서로 다른 비회원 기록 격리, 가입·기존 계정 로그인으로 기록 이전, 종료 확인.
- 503 오류 후 재시도 가능, 429 대기열 초과 후 마스킹 입력 유지와 재시도 확인.
- 격리된 PostgreSQL WASM 테스트에서 13개 비회원 세션 생성. AI 실행은 최대 2개, 실행·대기 합계 12개, 13번째 요청은 429 후 재시도 성공. 다른 세션의 작업 조회는 404.
- 위 동시 처리·브라우저 회귀 검사는 결정적 AI 응답을 사용한다. 실제 운영 서버의 대규모 부하나 모든 AI 응답 품질을 보장하는 검사는 아니다. 배포 후 실제 사이트 결과는 해당 PR에 기록한다.

## 교실에서 안내할 내용

- 링크를 열고 가입 없이 시작하기를 누른다. API 키나 발표자 계정은 공유하지 않는다.
- Render 무료 서버의 휴면 해제는 오래 걸릴 수 있으므로 발표 직전에 미리 열어 메인 화면을 확인한다.
- 동시에 많은 사람이 AI 작업을 요청하면 대기할 수 있다. 대기열이 찼다는 안내가 나오면 입력을 유지한 채 잠시 후 다시 누른다.
- 공용 PC에서는 비회원 메뉴의 기록 삭제하고 종료를 사용한다.

## 참고한 화면 구성 원칙

- [DeepL Translator](https://www.deepl.com/en/translator): 본문 입력과 작업 선택을 바로 찾는 흐름을 참고해 시작 동작을 우선 표시한다.
- [Notion 검색](https://www.notion.com/help/search): 검색·필터로 기록을 찾는 방식을 검토했다. 기존 기능이 있어 중복 메뉴를 추가하지 않았다.
- [GOV.UK 오류 안내](https://design-system.service.gov.uk/components/error-message/): 입력 도움말의 연결과 이해할 수 있는 오류 안내를 참고했다. 서비스 장애는 입력 잘못으로 표시하지 않는다.

외형을 복제하거나 이 서비스들보다 우수하다고 주장하지 않는다. 변경은 사용자가 시작하고 입력을 확인하는 과정에 집중한다.
