# ADR 0017 — 직접 가져오는 이메일 문의와 영어 지원

- 상태: 채택
- 날짜: 2026-11-15
- 변경하는 결정: ADR 0015의 환불·교환 중심 범위와 번역 제외 결정을 사용자의 이메일·계정 복구·영어 문의 지원 요청에 따라 확장한다. 메일함 자동 연결·발송은 추가하지 않는다.

## 결정

1. 기존 상담 문서에 선택적 `channel: email`을 저장한다. 기존 SQLite 기록과 일반 상담 API는 유지한다. 이메일 본문 붙여넣기와 4MB 이하 캡처 한 장을 기존 전송 전 가림·원문 검토 흐름에서 처리한다. 영어 캡처는 로컬 OCR의 `eng` 모델을 선택할 수 있고 기존 `kor+eng` 기본값을 유지한다.
2. 이메일 전사에는 헤더·인용 대화·발신자·시간대 지침을 추가한다. 원문 언어를 유지하고 공백·인용 기호를 정규화한 실제 부분 문자열인지 서버에서 검사한다. 발신자는 불명확하면 `unknown`이며 사용자가 확인해야 저장한다. 확실한 시간대가 없으면 시각을 비운다.
3. 인용 중복과 이미 저장된 같은 발언은 정리한다. 발신 역할과 본문이 같아도 서로 다른 명시적 날짜면 별도 메시지로 보존한다. 날짜가 없고 문장이 완전히 같은 반복 발언은 중복으로 간주될 수 있어 검토 화면에서 보완할 수 있다. 여러 새 메시지는 전체 검증 후 한 번에 저장한다.
4. 한국어 설명은 별도 실행하는 `email-explanation` 작업이다. 고객센터 원문 전체 인용과 메시지별 한국어 설명을 생성하고, 원문 일치·누락 검사와 별도 AI 의미 검토를 통과해야 저장한다. 새 메시지 뒤에는 기존 설명을 이전 답변 기준으로 표시한다. 실패·취소·버전 충돌은 기존 설명과 초안을 덮어쓰지 않는다.
5. 영어 재문의는 기존 선택 질문·근거·생성 후 검토·최대 한 번 수정 흐름을 사용한다. 이메일의 기본 재문의 언어는 영어이며 한국어로 바꿀 수 있다. 일반 상담의 기본값과 한국어 인계는 유지한다. 첨부나 제출을 원문 없이 완료했다고 주장하지 않으며 사용자가 수정·복사·발송한다.
6. 이메일에만 분석·업체 요청 해석 지침을 추가한다. 질문·설명은 한국어, 근거와 조건·기한은 원문으로 보존한다. 제출 대상의 수식어와 실제 선행 조건을 구분하며 자료 수신·심사·계정 복구·사용자의 직접 확인을 혼동하지 않는다. 기존 일반 상담 프롬프트와 호출 수는 바꾸지 않는다.

## 검증과 한계

[이메일 검증 기록](../EMAIL-INQUIRIES-VALIDATION.md)에 자동·브라우저·실제 API 평가를 구분한다. 한국어 설명은 완벽한 번역 보장이 아니며 원문을 함께 제공한다. 일반 상담에서 지원하던 제한된 기한 계산을 그대로 쓰므로 영어 영업일 등을 임의의 날짜로 변환하지 않는다. 메일함 연결, 자동 발송, 첨부 전달·수신 감지, 비밀번호 복구 실행, 메모·알림은 구현하지 않는다.
