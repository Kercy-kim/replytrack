# ADR 0033 — 링크 접속 후 간단 회원가입

- 상태: 채택
- 날짜: 2026-11-17
- 대체 범위: ADR 0031·0032의 초대 코드 가입 방식

사용자 요청에 따라 공개 링크에서 아이디·비밀번호로 바로 가입하도록 변경한다. 비밀번호 확인은 화면에서 확인하며 비밀번호 최소 12자 기준과 scrypt 해시 저장은 유지한다. 가입 직후 서버 세션을 발급하고 로그인한다. 초대 코드 발급 API와 관리자 버튼, 가입 폼의 코드 입력·검증·소비 로직을 제거한다.

신규 계정은 클라이언트가 보낸 ID·역할과 무관하게 서버가 생성한 ID와 participant 역할을 사용한다. 계정별 문의 소유권·세션·CSRF·로그인 및 가입 시도 제한은 유지한다. 동시 가입은 제어 행 잠금으로 직렬화하여 아이디 중복과 기존 참여자 최대 10명 설정을 지킨다. 인원이 찬 뒤에도 기존 사용자의 로그인과 문의 사용은 유지한다.

기존 사용자·비밀번호·세션·문의·사용량을 변경하지 않는다. 과거 DB의 rt_invites 테이블은 읽거나 쓰지 않으며 파괴적 마이그레이션을 하지 않는다. 새 DB에는 해당 테이블을 만들지 않는다.

링크를 아는 누구나 정원 내에서 가입할 수 있다. 초대받은 특정인만 이용할 수 있다고 설명하지 않는다. AI 판정 로직은 변경하지 않고, 유료 테스트는 배포 후 짧은 연결 점검 1회만 수행한다. [검증 기록](../SIMPLE-SIGNUP-VALIDATION.md).
