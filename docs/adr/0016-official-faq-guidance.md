# ADR 0016 — 요청 시 SSG 공식 FAQ 검색과 대체 안내

- 상태: 채택
- 날짜: 2026-11-15

## 결정

- SSG 일반 상품의 취소·반품·교환·환불만 먼저 지원한다. AI가 자연어 의도를 구분하면 의도별 정해진 질문으로 필요한 상황을 한 가지씩 확인한다. 모른다는 응답은 사실로 추정하지 않는다.
- 별도 검색 API를 쓰지 않고 SSG 공식 고객센터의 공개 검색 페이지를 직접 요청한다. 의도별 고정 주제어 1~3개만 보내고 개인 입력·전화번호·주소는 검색 URL에 보내지 않는다. 임의 URL, 로그인, 자동 주문 조작, 리다이렉트 추적을 지원하지 않는다.
- 전체 검색은 10초, 각 응답은 1.5MB로 제한한다. 질문/답변 구조가 확인되는 본문만 읽고 관련 자료 최대 6건·16,000자를 사용한다. 특수 서비스 FAQ는 제한적으로 제외한다. 전체 검색 결과와 개별 상품 정책을 수집했다는 의미가 아니다.
- 카드 환불 반영 시점 문의는 결제수단 정책 자료가 있으면 그 자료로 근거를 좁힌다. 관련 없는 반품 검수·추가 결제 절차를 일반 환불 안내에 섞지 않기 위한 검색 단계의 제한이며, 금액 차이 등 다른 문의에는 같은 제한을 적용하지 않는다.
- 빈 결과·비HTML·HTTP 실패·응답 크기 초과·구조 변경·시간 초과는 사전 검토 요약으로 전환한다. 검색 실패 이유는 일반적인 설명으로 표시하고 원래 확인 날짜를 유지한다. 실시간 결과와 대체 자료를 섞거나 대체 자료를 최신이라고 표시하지 않는다. 취소 신호는 대체 성공으로 바꾸지 않는다.
- 서버가 본문에서 180자 이내의 연속 인용 후보를 만들고 AI는 제한된 evidence ID 중 하나를 선택한다. 인용문·source ID는 서버가 복원한다. 실제 source ID와 연속 인용문을 검사하고 한 번의 AI 의미 검토로 근거·조건·예외를 대조한다. 실패하면 결과를 반영하지 않는다. 자동 재시도 루프는 없다. 기존 연결 사전 점검·진행 단계·경과 시간·취소를 재사용한다.
- 안내는 탭 메모리에 보관한다. 취소·실패 시 이전 결과와 입력을 보존하며 입력 변경 후 이전 안내를 명시한다. 상담 등록으로 넘길 때 마스킹된 사용자 요청·상황만 customer 원문으로 옮기고 FAQ나 AI 설명을 agent 원문으로 만들지 않는다. 작성 중인 등록 내용을 덮어쓰지 않는다.

## 한계

실제 SSG 검색 성공을 확인했지만 사이트 구조·정책은 바뀔 수 있다. 대체 자료는 수동으로 검토·갱신해야 한다. 검색 서비스의 정답률이나 AI 검토의 완전성을 보장하지 않는다. 공개 다중 사용자 서비스로 배포하기 전 검색 빈도 관리와 자료 이용 방식 검토가 필요하다. 모의 검증 후 실제 OpenAI 기본 사례도 점검했으며 결과와 한계는 [검증 기록](../OFFICIAL-GUIDE-VALIDATION.md)에 구분한다. 확대 품질·성능 평가는 남아 있다.
