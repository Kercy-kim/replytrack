# ADR 0022 — 발표 핵심 흐름과 문의별 공식 참고 안내

- 상태: 채택
- 날짜: 2026-11-15
- 대체: ADR 0002의 Chrome 확장 제공, ADR 0016의 별도 SSG 입력 화면·대체 자료 안내. 과거 평가 자료는 당시 구현의 기록으로 보존한다.

## 결정

사용자 요구에 따라 Chrome 확장 코드·설치 경로·전용 CORS 예외를 제거한다. 웹의 본문 붙여넣기·로컬 캡처 입력은 유지한다. 앞으로 개발·발표는 문제와 목적, 예상 사용자·활용 상황, 사용자 필요, 핵심 기능 3개 이상, 기능별 AI 역할, 입력→처리→출력을 기준으로 판단한다. 30초 시연의 핵심은 질문별 분석 → 새 답변의 변화 → 남은 질문의 영어 재문의이며 지금 내가 할 일은 함께 설명한다.

공식 안내는 별도 상담 챗봇 대신 기존 문의에 붙는 선택적 참고 영역으로 바꾼다. 문의처·주제가 명확한 경우에만 확인된 공식 URL의 현재 본문을 조회한다. 지원 목록은 SSG 일반 상품, Google·Microsoft·Apple 계정 복구다. 임의 입력 URL·유사 도메인·이메일 주소만으로 공식 사이트를 판정하거나 가져오지 않는다. 알 수 없는 업체·지원 밖 주제는 생략한다.

공식 안내 생성과 독립 검토가 원문 근거·적용 조건·문의와의 관련성·기존 답변과의 비충돌을 모두 통과해야 한 항목을 표시한다. 출처 링크·짧은 인용·조회 날짜를 표시한다. 현재 본문 확보 실패, 오래된 대체 자료, 불확실성, 검토 실패는 빈 안내로 처리한다. 공식 일반 기준을 개별 상담 답변·질문 상태·실제 해결 결과에 섞지 않는다. AI 검토는 정확성을 보증하지 않으며 불필요한 안내를 생략하는 쪽으로 설계한다.

조회·검토는 주 분석과 별도 요청으로 실행하고 문의 상세의 안내 영역만 갱신한다. 결과는 서버 메모리에 최대 30분·100개, 동시에 최대 2건으로 제한한다. 원문·문의처 변경 시 다른 키를 사용하고 이전 안내를 즉시 감춘다. 작업 종료 시 취소하고 미완성 결과는 게시하지 않는다. 외부 웹사이트에는 사용자 문의문을 전송하지 않으며 SSG에는 고정 주제어만 전송한다. AI에는 기존 개인정보 가림 경로로 검토 자료를 전달한다.

공식 안내의 관련성이 확인됐지만 근거·조건 보완이 필요한 경우에만 피드백으로 한 번 수정하고 다시 검토한다. 최대 4회 호출·전체 60초 안에 검토를 통과하지 못하면 표시하지 않는다. 관련성·충돌 실패는 이 경로로 우회하지 않는다.

## 영어 새 답변 성능

고객의 새 질문이 없는 이메일 답변 추가에서는 질문 제목·원문·ID를 로컬에서 보존한다. 모델에는 전체 대화와 기존 질문·약속을 계속 제공하며 상태·이유·근거·후속 질문·약속은 다시 판단한다. 짧고 단순한 문맥만 low를 사용하고 조건·정정·긴 대화는 medium을 유지한다. 처음 읽는 이메일·새 고객 질문·불명확한 발화자는 전체 분석을 사용한다. 잘못된 응답은 전체 스키마와 medium으로 한 번 수정하고 원문·발화자·상태 검증을 다시 수행한다.

영문 인용의 비연속 문장 결합은 각 문장이 원문에 정확하고 유일하게 존재하며 순서가 일치할 때만 독립 인용으로 분리한다. 원문 단어·문장부호를 고치거나 누락된 내용을 추측하지 않는다. 처리 통보·경계 의미 검토와 버전·취소 보호를 유지한다.
