# ADR 0023 — 네 핵심 기능과 답장 작성에 집중

- 상태: 채택
- 날짜: 2026-11-15
- 확장: ADR 0022의 발표 핵심 범위. 과거 인계 최적화 결정은 현행 생성 기능에 적용하지 않는다.

## 결정

질문별 답변 분석, 지금 내가 할 일, 한국어 설명·재문의 작성, 새 답변 전후 비교를 네 핵심 기능으로 고정한다. 입력·원문 검토·검색·보관·내려받기는 이를 사용하기 위한 기반 기능이다. 공식 안내는 출처와 적용 조건을 검토한 경우에만 표시하는 보조 정보다. 별도 인계 요약 생성은 화면·서버 생성 경로에서 제거한다. 기존 저장된 요약은 삭제하거나 변환하지 않으며 내려받기에 포함한다.

과거 인계 프롬프트·순수 검증 도구와 평가 결과는 이전 실험의 재현 자료로 남긴다. 현행 서비스는 해당 생성·보정 코드를 호출하지 않는다. 과거 인계 전용 평가 전체를 재현하려면 당시 커밋을 사용한다. 새 범용 챗봇, 메일함 연동, 자동 발송, 알림·대시보드 확장은 현재 범위에서 제외한다.

## 답장 사용성

초안에는 생성 당시 선택된 질문 ID와 언어를 저장하고 화면에 질문을 표시한다. 사용자가 선택이나 언어를 바꾸면 초안을 다시 만들어야 함을 알려 주며 입력 중인 문장은 변경하지 않는다. 재진입 시 저장된 선택을 복원한다. 이전 기록에 생성 범위가 없으면 추측하지 않는다. 이것은 AI가 편집된 문장의 사실성을 재검증했다는 뜻이 아니다.

## 비교 원칙

Gmail의 요약·답장·할 일, NoReply의 사건별 맥락·다음 단계, Resolver의 개인 문의 기록은 이미 있는 기능이다. 다음 행동을 알아보기 쉽게 하고 발송 전에 내용을 확인하는 원칙을 참고하되, 화면·문구를 복제하지 않는다. ReplyTrack은 질문별 충족 여부·근거·상태 변화·실제 결과 확인을 연결하는 흐름에 집중한다. 시장 유일성이나 경쟁 제품보다 좋은 효과를 주장하지 않는다.

공식 출처와 검증 범위: [공식 안내 웹 검증·제품 집중](../OFFICIAL-WEB-CORE.md).

공식 참고 안내 검토에는 관련성 외에 질문에 직접 답하는지 확인하는 `answersQuestion`을 추가한다. 개인별 완료일·처리 상태를 확정하는 질문에 공개 자료의 일반 조회 방법을 대신 내놓으면 생략한다. 필수 적용 조건과 선택 권고를 구분하며, Microsoft의 `working email`은 수신 가능한 연락용 이메일로 설명한다. 불확실성·충돌 생략과 기존 호출·시간 제한은 유지한다.
