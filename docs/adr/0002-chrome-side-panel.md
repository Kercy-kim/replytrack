# ADR 0002 — 선택 영역을 사용하는 Chrome 사이드 패널

- 상태: 대체됨 — 현재 제공 범위는 [ADR 0022](0022-presentation-core-focus.md)를 따른다. 아래는 당시 결정의 기록이다.
- 날짜: 2026-11-14

## 결정

기존 웹을 유지하고 빌드 없는 Manifest V3 확장 프로그램을 추가한다. 아이콘과 우클릭 메뉴에서 사용자가 선택한 텍스트만 가져온다. 전송 전 편집과 AI 전사 후 발화자 검토를 제공한다. 결과는 기존 분석·근거 검증·초안 생성·SQLite 서비스를 재사용한다.

패널은 입력·검토·결과의 세 단계이며, 창별 편집 상태는 확장의 session 저장소에 보관한다. 같은 상담은 웹에서도 볼 수 있다. 질문 상태 수정, 새 메시지 추가, 실제 처리 확인은 웹에서 유지하고 패널은 새로고침으로 반영한다.

ADR 0001의 루프백·단일 사용자 범위는 유지한다. 기존의 동일 출처 전용 정책에 **고정 확장 ID 한 개의 필요한 API 요청**을 예외로 추가한다. 서버는 공개 manifest key에서 허용 출처를 계산하며 GET 상태·개별 상담 조회, POST 전사·상담 생성·분석·초안 생성만 허용한다. 다른 사이트·확장 출처, API 설정 변경, 삭제는 허용하지 않는다. Origin이 없는 로컬 클라이언트에 대한 기존 정책은 바꾸지 않으므로 이것은 사용자 인증이 아니다.

API 키는 계속 서버에만 보관한다. 확장은 OpenAI에 직접 연결하지 않는다. 페이지 DOM과 외부 메시지를 통한 임의 네트워크 요청 프록시는 만들지 않는다.

## 결과와 제한

기존 AI와 상태 로직을 복제하지 않고 상담 화면 옆에서 사용할 수 있다. 로컬 서버를 실행해야 하고, 배포·다중 사용자 인증은 별도 설계가 필요하다. 선택이 불가능한 대화나 프레임 권한 문제에는 우클릭 선택 가져오기 또는 직접 붙여넣기를 사용한다. 어떤 챗봇에서나 전체 대화를 자동 수집한다는 보장은 없다.

공개키는 개발 ID 고정용이며 스토어 배포 서명 키가 아니다. 스토어 배포 시 발급받은 공개키로 ID와 허용 출처를 함께 검토해야 한다.
