# ADR 0013 — 인계 대기 질문 범위와 제한된 발화자 정리

- 상태: 채택
- 날짜: 2026-11-14
- 관련 결정: [ADR 0006](0006-question-status-boundaries.md), [ADR 0011](0011-source-grounded-handoff-attribution.md)

## 문제

전체 회귀 평가에서 인계 검토가 업체의 부가 미정 정보를 새로운 대기 질문으로 허용했다. 반대로 대기 대상이 올바른 초안의 배경 설명을 추가 질문으로 오인하기도 했다. 질문의 미해결 상태와 원문 사실을 한꺼번에 서술한 문장을 구별할 필요가 있다.

또한 기존 발화자 정리에서 다루지 않았던 “상담원 중 한 쪽은 …다고 안내했고 다른 쪽은 …다고 안내하여” 표현이 저장됐다. 대화에는 agent 역할만 있어 실제 상담원 수는 알 수 없다. ADR 0011의 세 표현만 허용한다는 결정은 이 관측 사례를 포함하도록 한정해서 확장한다.

## 결정

인계 생성·검토·수정 모두에 서버가 현재 유효한 상태로부터 만든 `pendingQuestions`를 전달한다. 사용자가 직접 변경한 상태를 존중하며, 답변 받음 질문은 대기 목록에서 제외한다. 전체 질문과 메시지는 요약의 사실 검증을 위해 그대로 전달한다. 재문의의 선택 질문 범위에는 영향을 주지 않는다.

검토는 업체의 과거 안내를 전달하는 배경 문장과 소비자가 지금 답변을 기다리거나 요청하는 문장을 구분한다. 원문에 있는 부가 미정 사실은 배경으로 허용한다. 실제 대기·요청 대상만 목록과 비교하며, 실패 피드백은 추가된 요청 문구를 특정한다.

발화자 정리는 위의 짝을 이룬 간접 안내 표현의 주체만 “한 답변에서는/다른 답변에서는”으로 바꾼다. 원문에 실제 담당자 표현이 없고 유효한 서로 다른 agent 출처가 두 개 이상일 때만 적용한다. 사실·서술어·순서·출처는 바꾸지 않으며 같은 전체 원문 medium 검토를 반드시 거친다. 미지원 “상담원 중 한 쪽/분/명” 추정은 서버 검증에서 거절해 기존 수정 경로를 따른다. 행동이나 다른 상담원에게 하는 요청은 이 규칙으로 고치지 않는다.

모델, 추론량, 호출 한도, 원문·숫자·출처 검증과 실패 시 기존 기록을 보존하는 원칙은 유지한다. 같은 처리의 방법만 안내받은 실제 상태 질문은 ADR 0006대로 부분 답변이며, 미답변 형식에 맞추려고 관련 근거만 지우지 않도록 분석·수정 지침을 명확히 한다.

미답변은 관련 안내가 없다는 단일 의미다. 근거 검증을 통과한 이 상태의 표시 이유는 서버에서 “관련 안내가 아직 없어 답을 확인할 수 없음”으로 정한다. 자유 생성한 설명이 원문 없는 주문번호·신분증 제출 등의 선행 요건을 사용자에게 요구하지 못하게 한다. AI가 선택한 상태와 근거는 수정하지 않으며, 인용과 모순되는 미답변의 확인 필요 전환·사용자 수동 상태는 기존대로 우선한다. 나머지 상태의 문맥 설명은 유지한다.

## 검증과 한계

고정 상담 48건·인계 생성 18회 및 정상/오류 초안 대조를 실제 API로 평가한다. 실패·중간 실행과 최종 결과는 [전체 회귀 보고서](../FULL-AI-REGRESSION.md)에 구분해 기록한다. 단위 테스트는 수동 상태 반영, 생성·검토·수정의 동일한 대기 목록, 관측 표현 정리, 실제 담당자 정보·행동·잘못된 근거의 보존 및 검증을 확인한다. 같은 모델의 자기 검토만으로 모든 의미 오류를 막을 수 없으므로 저장 성공과 원문 대조 통과를 구분한다.
