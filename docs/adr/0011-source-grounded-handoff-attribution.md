# ADR 0011 — 원문 인용에 근거한 인계 발화자 표현 정리

- 상태: 채택
- 날짜: 2026-11-14
- 이전 결정: [ADR 0010](0010-focused-handoff-repair.md)

## 문제

PR #8의 U06 인계는 45.575초가 걸렸다. 첫 생성 7.289초 뒤, 원문에 없는 '한 상담원/다른 상담원' 구분을 서버가 거절했다. medium 수정 17.395초, medium 검토 20.891초가 추가됐다. 두 상반된 답변은 실제 원문과 일치하지만 담당자가 서로 다른 사람이라는 근거는 없었다.

## 결정 후보

검토 지침, 모델, 추론량과 호출 한도는 그대로 유지한다. 인계에만 좁은 범위의 결정적 표현 정리를 적용한다. 원문과 일치하는 두 인용을 전달하는 '한 상담원은 …라고 안내했고, 다른 상담원은 …라고 안내받아' 같은 표현에서 '한 답변에서는/다른 답변에서는'으로 바꾼다. 앞뒤 시간 순서나 실제 인원수를 추론하지 않는다.

출처 ID가 모두 유효하고 서로 다른 agent 메시지 두 개 이상을 가리켜야 한다. 원문 자체에 상담원·상담사·담당자 또는 한 분·다른 분 표현이 있으면 보수적으로 정리하지 않는다. 허용하는 표현은 다음 세 종류다.

- 두 개의 닫힌 직접 인용과 안내·설명·답변 동사: '한/다른' 순서의 정확히 두 표현이며 두 인용이 서로 다른 출처 원문에 실제 존재해야 한다.
- '한/다른 상담원에게는 …라고/다고/고 안내받았고/아' 형태의 간접 안내 전달: 정확히 두 표현의 사람 구분만 '한/다른 답변에서는'으로 바꾼다. 다른 담당자 표현을 가로질러 행동 절을 소비하지 않는다.
- '상담원들로부터 …인용… 안내를 받았다' 형태: 근거 없는 복수 접미사만 제거해 '상담원으로부터'로 쓴다. 개인 수를 확정하는 '한 명'으로 바꾸지 않는다.

간접 인용과 복수형의 내용 일치는 기존 의미 검토가 담당한다. 이름·실제 담당자 정보·행동·다른 상담원에게 하는 요청·허용하지 않은 문장·알 수 없는 근거는 일반 검증·수정 경로를 따른다.

사실·인용·서술어·출처는 바꾸지 않는다. 기존 서버 검증 뒤 전체 원문을 보는 medium 의미 검토를 반드시 거쳐 저장한다. 다른 오류가 있으면 기존 medium 수정과 최종 검토를 실행하며, 실패·충돌 시 편집된 초안을 보존한다. ADR 0010의 추론량·검토 원칙을 유지하며, 단순 ID 표기 정리를 제한적인 발화자 표현 정리로 확장하는 결정이다.

중간 후보에서 NR05가 잘못된 중간 안내를 '초기'라고 서술해 50.520초가 걸렸다. 정정 정보의 생성 지침도 바꿔 보았지만 새 전체 비교에서 같은 오류가 재발했고, 인용 없는 담당자 추정도 발생해 p95·토큰이 악화됐다. 이 지침 후보는 제외하고 생성·수정 지침을 기준 구현 그대로 복원했다. 현재 변경은 위 발화자 표현 정리에 한정하며, 정정 순서 등 다른 오류의 재작업까지 없애지는 않는다.

## 검증

기준 main `e7717f8`에서 원문·분석 상태·ID와 모델을 고정해 비교한다. 기존 12개 기록에서 U06 6회, NR05 3회, R03 2회, 나머지 각 1회로 전후 20쌍이다. 별도 실패 초안 재생은 실제 45.575초 사례, 담당자·따옴표 변형, 중간 후보에서 관측한 복수형·간접 안내, 기존 R03·H02의 6개 초안을 각 2회 실행한다. 재생한 첫 실패 생성·검토의 시간은 합산하지 않고 수정·검토 경로만 측정한다. 추가한 관측 초안도 최종 API 호출 전에 별도 자료로 고정했다.

최종 전체 생성 20/20회, 별도 수정 재생 12/12회가 저장·원문 대조를 통과했다. 전체 자동 테스트 94개와 문법 검사 51개 파일을 통과했다. 같은 실패 초안의 재생에서 대상 표현 8회는 재생성 한 번씩을 제거했으며, 12회 전체 중앙값 21.308→9.760초, 총 토큰 59,240→37,782였다. 의미 수정이 필요한 대조 4회는 기존 경로를 유지했다.

전체 생성 20회의 최장 시간은 46.487→34.592초, 45초 초과는 1→0회였지만 p95는 33.003→33.255초였다. 이 전체 실행에서 새 표현 정리 적용은 0회이므로 전체 관측 차이를 새 코드의 인과적 효과로 주장하지 않는다. 적용 경로의 검증과 광범위 회귀 확인을 구분해 채택한다. [평가 보고서](../HANDOFF-ATTRIBUTION-PERFORMANCE.md)에 중간 후보와 실패·한계를 보존했다.
