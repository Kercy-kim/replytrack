# ADR 0031 — 10명 평가를 위한 PostgreSQL과 개인 계정

- 상태: 채택
- 날짜: 2026-11-17
- 대체 범위: ADR 0030의 공유 작업 공간·임시 SQLite 저장

## 결정

2주간 최대 참여자 10명과 관리자 1명을 운영한다. Render 웹 서비스와 같은 Singapore 지역의 무료 PostgreSQL을 연결한다. `DATABASE_URL`이 있으면 DB 기반 계정·세션·문의 소유권을 사용하며 없으면 기존 로컬 SQLite/공개 Basic 인증 동작을 유지한다.

관리자 `replytrack`은 기존 `REPLYTRACK_DEMO_PASSWORD`로 처음 한 번 생성한다. 비밀번호는 scrypt 해시로 저장한다. 이후 재시작 때 초기 비밀번호로 덮어쓰지 않는다. 참여자는 관리자에게 받은 14일 유효 일회용 초대 코드로 아이디와 12자 이상 비밀번호를 등록한다. 이메일·전화번호·외부 로그인은 요구하지 않는다.

문의는 `owner_id`로 조회·변경·삭제를 제한하고 서버 세션으로 소유자를 결정한다. 사용자가 보낸 소유자 ID는 신뢰하지 않는다. 버전 조건을 포함한 UPDATE로 동시 변경 덮어쓰기를 막는다. 세션과 초대 코드 원문은 저장하지 않고 SHA-256 해시를 저장한다. 세션 쿠키는 HttpOnly·SameSite=Strict, 공개 HTTPS에서 Secure이며 7일 후 만료한다. 변경 요청의 Origin을 검증한다.

작업 상태 조회·취소도 계정별로 제한한다. 계정당 실행·대기 합쳐 1개, 전체 작업 2개 실행, 전체 대기 포함 12개까지 받는다. OCR은 서버 메모리를 고려해 한 번에 하나만 실행한다. 진행 중 작업은 메모리에 있으므로 서버 재시작으로 종료될 수 있지만 저장된 문의·계정은 PostgreSQL에 남는다.

한국 시간 하루 AI 작업은 참여자 30회/관리자 100회, 문의는 계정당 30개로 제한한다. 한 작업이 여러 모델 호출을 포함하므로 호출 수·토큰·금액 상한과 같지 않다. 공식 안내 생성도 사용량에 포함하며 캐시와 적용되지 않는 안내는 차감하지 않는다. 시작한 뒤 실패·취소한 작업은 집계에 남는다. 텍스트 가림·OCR은 AI 작업 횟수에서 제외하되 동시 처리 제한을 적용한다.

## 경계와 운영

관리자 화면에는 사용자 문의 열람 기능을 만들지 않는다. DB 운영자는 저장소 자체에 접근할 수 있으며, 사용자 간 분리는 종단간 암호화가 아니다. 자동 비밀번호 재설정·메일함 수집·자동 발송은 추가하지 않는다. 기존 공유 SQLite 기록은 새 계정에 자동 배정하지 않는다.

무료 PostgreSQL은 생성 30일 뒤 만료하므로 2주 평가 종료 전 개인별 기록을 내려받는다. 웹 서비스 절전 후 첫 접속 지연은 남는다. 무료 호스팅과 OpenAI API 이용 비용은 별개다. 검증 범위는 [다중 사용자 검증](../MULTIUSER-VALIDATION.md)에 기록한다.
