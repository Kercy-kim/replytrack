# ADR 0030 — 학교 PC 시연을 위한 비밀번호 보호 배포

- 상태: 채택
- 날짜: 2026-11-17
- 변경 대상: [ADR 0001](0001-local-mvp.md)의 로컬 실행 범위

## 배경

사용자가 자신의 노트북 대신 학교 컴퓨터에서 ReplyTrack을 시연해야 한다. 별도 설치 없이 접속할 HTTPS 주소가 필요하다.

## 결정

Render Free의 Node Web Service를 `replytrack` 이름으로 준비한다. 로컬에서는 기존 루프백 바인딩을 유지하며 공개 주소가 명시되거나 Render 환경일 때만 `0.0.0.0`을 사용한다. 공개 주소는 서버 환경변수에서만 신뢰한다.

공개 실행에는 16자 이상 비밀번호를 필수로 지정한다. HTTPS에서 HTTP Basic 인증으로 화면·상담 기록·AI 설정·발표 재생을 보호한다. 사용자 이름은 `replytrack`이다. 상담·모델 정보를 포함하지 않는 상태 확인 경로만 인증에서 제외한다. Host·Origin 및 교차 출처 요청을 검사한다. 비밀번호와 API 키는 저장소에 넣지 않는다.

이는 발표자용 단일 작업 공간이다. 비밀번호 보유자들은 동일한 기록과 API 설정에 접근하며 일반 고객 대상 회원 서비스나 다중 사용자 배포가 아니다. ADR 0001에서 제시한 사용자별 기록 분리·일반 공개 사용의 요청 및 비용 제한은 여전히 별도 설계가 필요하다. 기존 작업 동시 실행 제한은 유지하지만 계정별 사용량 제한은 제공하지 않는다. 발표에는 가상 입력을 사용하고 비밀번호를 공개하지 않는다.

## 결과와 검증

Render Free는 영구 디스크를 지원하지 않으므로 재시작·재배포·절전 시 상담 기록이 소실될 수 있다. 사전 실행 결과 재생은 저장소 파일을 사용한다. 외부 호스팅에 전달되는 문의 원문과 캡처는 학교 시연용 가상 자료로 한정한다.

접근 보호·출처 검사·인증 우회 방지 테스트를 포함한 자동 테스트 277개와 JavaScript 144개 파일 문법 검사를 통과했다. AI 프롬프트·판정 로직은 수정하지 않았다. 실제 Render 배포 성공과 배포된 브라우저 흐름 확인은 별도로 수행한다. 설정과 접속 절차는 [배포 안내](../RENDER-DEPLOYMENT.md)를 따른다.
