# ADR 0010 — 인계의 제한된 수정과 긴 지연 감소

- 상태: 채택
- 날짜: 2026-11-14
- 이전 결정: [ADR 0009](0009-handoff-specific-generation.md)

## 문제

이전 최종 비교의 R03 인계는 51.875초였다. 첫 생성 5.539초 뒤, '확인 중'을 '환불 예정일 미정'으로 요약한 부분을 검토가 거절했다. 첫 검토 20초, 전체 초안 재생성 13.470초, 재검토 12.866초가 필요했다. 생성 지침 자체에 '환불 예정일이 미정입니다'라는 예시가 있어 이 재작업을 유발할 수 있었다. NR05에서는 본문 내부 ID를 검증이 차단해 30.933초가 걸렸다.

## 결정

생성 예시를 '환불 예정일에 대한 답변을 기다리고 있습니다'로 바로잡는다. 안내받지 못한 정보와 실제 일정 자체가 미정이라는 단정을 구분한다.

인계 수정에는 별도의 제한된 수정 지침을 사용한다. 기존 초안·검토 피드백·원문·질문·약속을 모두 보내고, 오류와 직접 관련된 표현을 수정하면서 원문의 시간 순서와 담당자 구분도 확인한다. low 수정 후보는 실제 비교에서 순서·담당자 오류로 실패해 제외했다. **ADR 0009의 의미 수정 medium 결정을 유지**한다. 인계 첫 생성은 기존 low, 모든 의미 검토도 기존 medium이다.

현재 상담의 내부 메시지 ID만 들어 있는 순수 괄호·대괄호 인용은 코드로 표기를 제거한 뒤 기존 검증·의미 검토를 실행한다. 사실·문장 순서·sourceMessageIds는 바꾸지 않는다. 원문에 실제로 등장한 식별자, 다른 상담의 ID, 일반 본문이나 다른 글과 섞인 ID는 제거하지 않고 기존 검증·수정 절차로 처리한다. 실패한 최초 출력은 평가 기록에 그대로 남긴다.

의미 검토 지침은 기존과 동일하다. 표기를 정리한 결과에도 원문 참조·숫자·기한·담당자 검증을 적용한다. 한 번의 수정 한도, 최종 검토 통과 후 저장, 실패·충돌 시 기존 편집 초안 보존도 유지한다. 검토를 생략하거나 미완성 문장을 표시하지 않는다.

## 검증

기준 main `67b8e5a`와 동일한 고정 모델로 비교한다. 기존 분석 기록 12개에서 R03은 6회, NR05는 4회, 나머지는 한 번씩 전후 각 20회 전체 인계를 생성한다. 별도로 보존한 실패 초안 4개와 동일한 피드백을 재생하여 수정·최종 검토만 전후 각 8회 비교한다. 서버 검증에서 거절됐던 초안에는 가짜 의미 검토 실패를 추가하지 않으며, 표기만 정리한 결과도 실제 AI 검토를 받는다. 이 재생 측정에는 첫 생성·첫 검토의 실제 시간이 없으므로 전체 인계 시간에 합치지 않는다.

개선안의 전체 인계 20/20회와 수정 재생 8/8회가 저장·원문 대조를 통과했다. 전체 인계의 50초 초과는 1→0회, 최장 시간은 54.919→45.575초, 중앙값은 18.035→15.597초, p95는 22.639→21.683초였다. 총 토큰은 5.31% 줄었다. 자동 테스트 86개와 문법 검사 49개 파일을 통과했다. 의미 검토 지침의 동일성을 확인했으며 이전 검토 대조 16개를 이번 신규 실행에 포함하지 않았다.

수정 재생의 기준 실패 2회를 포함하면 중앙값과 총 토큰은 증가했다. 전체 생성에서도 U06 한 쌍은 수정이 발생해 느려졌다. 이런 결과와 제외한 low 후보를 [후속 보고서](../HANDOFF-TAIL-PERFORMANCE.md)에 남긴다. 작은 반복 표본의 개선이며 모든 인계가 50초 안에 끝난다는 보장은 아니다.
