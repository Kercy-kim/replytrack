# ADR 0012 — 웹 AI 작업의 취소와 전송 전 개인정보 가림

- 상태: 채택
- 날짜: 2026-11-14
- 이전 결정: [ADR 0001](0001-local-mvp.md)의 외부 패키지 없는 구현 결정을 **로컬 OCR에 한해 변경**한다. 로컬 단일 사용자·SQLite·빌드 없는 웹 구조는 유지한다.

## 배경

긴 AI 작업의 처리 단계를 알 수 없고 취소할 수 없었다. API 키 등록 표시만으로 연결을 검증할 수 없었으며 캡처 원본을 외부 AI에 보내면 전송 전 마스킹을 보장할 수 없었다. 사용자는 웹 개발, 연결 사전 점검, 실제 단계·경과 시간, 취소 시 입력·기록 보존과 기본 전화번호·주소 마스킹을 요청했다.

## 결정

1. 웹은 UUID로 비동기 작업을 접수하고 0.5초마다 상태를 조회한다. 단계는 서비스가 실제 호출·검증·수정을 시작할 때 기록한다. 완료율이나 예상 대기 시간을 만들지 않는다.
2. 취소는 서버 AbortController에서 공급자 요청·응답 읽기와 OCR 작업자로 전파한다. 호출 후와 저장 전에도 신호를 검사해 공급자가 늦게 응답해도 기존 기록을 덮어쓰지 않는다. 완료가 취소보다 앞서면 완료 결과를 안내하며 소급 취소하지 않는다.
3. 입력 메시지의 저장과 분석은 분리한다. 새 메시지 추가로 이전 초안을 삭제하지 않고 `이전 분석 기준`으로 표시한다. 분석이 검증·저장됐을 때만 초기화한다. 미저장 화면 편집도 취소·실패 시 유지한다.
4. 짧은 실제 Structured Outputs 요청으로 연결을 점검한다. 상담 내용은 보내지 않는다. 설정 변경 때 점검을 무효화하며 통과 결과는 10분 재사용한다. 예제는 점검·유료 호출 없이 동작한다.
5. 캡처는 설치된 Tesseract.js·한국어·영어 모델로 로컬에서만 읽고, 텍스트의 전화번호·주소를 규칙으로 가린다. 웹 미리보기에서 추가 삭제·인식 수정 후 AI에 보낸다. 원본 이미지를 Responses API로 보내는 경로는 차단한다. 새 상담·추가 메시지의 저장 API에서도 가림을 적용한다.
6. 과거 기록을 강제 수정하지 않는다. API 클라이언트에서도 원문과 수정 지침을 가리고, 요청별 가림 대응표는 로컬 메모리에서만 사용한다. 알려진 표시를 로컬에서 복원하여 기존 원문 인용 검증을 유지한다. 가림 표시만으로 번호·주소의 동일성이나 변경을 추정하지 않도록 지시한다.

## 범위와 한계

별도 모바일·데스크톱 앱은 만들지 않는다. 이전 Chrome 확장은 호환성을 유지하되 새 진행·취소 UI는 웹에 제공한다. 작업 상태는 메모리에 최대 100건, 완료 후 10분까지 유지하며 DB에 작업 입력이나 키를 중복 저장하지 않는다. 서버 재시작 때 작업 상태가 사라져도 상담 DB는 유지된다.

모든 개인정보·해외 주소·비정형 표기·OCR 오인식을 자동 검출하지 못하므로 전송 전 확인이 필요하다. 로컬 OCR은 작은 글자·복잡한 화면에서 인식 정확도가 낮을 수 있다. 새 입력의 가림은 비가역적이며 기존 원문·내보내기는 과거 개인정보를 포함할 수 있다. 취소는 공급자의 이미 발생한 비용을 환불하는 기능이 아니다. 대규모 실제 AI 품질 평가와 모든 OCR 형식의 검증을 완료했다는 의미는 아니다.
