# ADR 0020: 첫 분석의 추론량 분기와 경계 검토 근거 보완

상태: 채택. 2026-11-15. ADR 0008의 모든 분석을 medium으로 실행한다는 결정을 일부 변경한다.

## 문제

등록과 새 답변 반영은 같은 전체 대화 분석을 호출한다. 작은 상담에도 첫 분석부터 medium 추론을 사용한다. 최신 main의 48건 실제 평가에서 생성 토큰 81,340개 중 65,728개가 추론 토큰이었다. 단순히 모든 첫 분석을 low로 바꾼 후보에서는 정정 날짜·발송 시점 판정과 근거 인용 누락이 발생해 채택하지 않았다.

## 결정

- 첫 분석은 기본 low로 실행하되, 이메일이거나 agent 원문에 정정·변경·철회 또는 조건·예외 등의 신호가 있거나 대화가 8개 메시지 또는 8,000자를 초과하면 medium을 유지한다. 신호는 추론량만 선택하며 질문 상태·금액·기한을 코드로 결정하지 않는다. 신호가 없다는 것이 의미적으로 단순하다는 보장은 아니다. 이메일은 low에서 제출 자료 오판·영문 질문 제목과 추가 검토 지연이 나타나 초기·후속 분석 모두 기존 medium을 유지한다.
- 인용 오류 수정, 부분 답변/확인 필요 경계 검토, 완료 통보 누락 검토는 medium을 유지한다. 원문·출력 한도·취소·버전 검사·수정 횟수는 줄이지 않는다.
- 시점 질문에 행동 예정일을 답한 경우와, 그 시점을 확인해서 알려주겠다는 경우를 분석 지침 앞부분에서 구분한다. 행동이 아직 실행되지 않았어도 예정일 질문에는 답변을 받을 수 있다.
- 경계 검토가 status·reason과 함께 evidence를 반환한다. 이전 초안의 인용 누락을 상태 변경 뒤까지 유지하지 않는다. agent ID를 스키마에서 제한하고, 반환 인용은 기존 원문 검증으로 다시 검사한다. 실패하면 결과를 저장하지 않는다. 질문 ID·source·약속은 검토 단계에서 바꾸지 않고 answered로 승격하지 않는다.
- 새 모델, 응답 캐시, 추정 결과 선표시, 사용자 설정은 추가하지 않는다.
- 이메일 제목은 한국어 패턴·설명과 서버 검사를 적용하고 위반 시 기존 medium 수정 기회를 사용한다. 일반 상담 스키마와 영어 원문 인용은 유지한다. 출력에 복사된 상태 라벨은 표시에서만 제거하고 사실·금액·원문은 다시 쓰지 않는다.

## 검증과 한계

배송·환불·구독 48건, 분석 55회에서 질문 상태·근거·약속·기한과 판정 이유를 확인한다. 전후 시간은 첫 분석과 새 답변 반영을 나누고 수정·검토 호출도 포함한다. 원문과 저장 결과는 개발 에이전트가 대조하며 독립 사람 검수나 실제 사용자 정확도로 설명하지 않는다. 정정·철회·조건부 안내 사례의 응답 시간까지 일괄 개선된 것은 아니다.

실측, 채택하지 않은 후보 및 웹 검증은 [분석 응답 시간 보고서](../ANALYSIS-LATENCY.md)에 기록한다. `reasoning.effort`의 의미는 [OpenAI 공식 문서](https://developers.openai.com/api/docs/guides/reasoning)를 참고한다.
