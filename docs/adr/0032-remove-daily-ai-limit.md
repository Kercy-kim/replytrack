# ADR 0032 — 일일 AI 작업 횟수 제한 제거

- 상태: 채택
- 날짜: 2026-11-17
- 대체 범위: ADR 0031의 참여자 30회·관리자 100회 일일 제한
- 후속 변경: 초대 코드 가입은 [ADR 0033](0033-simple-signup.md)에서 아이디·비밀번호 가입으로 대체했다.

## 결정

소수의 초대 참여자가 2주간 사용하는 운영 목적에 맞춰 하루 AI 작업 횟수로 차단하지 않는다. 계정 화면에는 오늘 사용한 작업 수만 표시한다. 사용량 기록과 동일 작업 ID 중복 접수 차단은 유지하며 기존 계정·문의·사용량 테이블은 변경하거나 삭제하지 않는다.

가입에는 관리자 발급 일회용 초대 코드가 필요하며 모든 문의 접근에는 로그인이 필요하다. 주소만 알아서는 문의 기능을 사용할 수 없다. 코드를 전달받은 사람이 가입할 수 있는 구조이므로 지정한 사람의 신원을 별도로 인증하는 것은 아니다.

참여자 10명, 계정별 문의 30개, 계정별 진행 작업 1개, 전체 실행 2개와 실행·대기 합계 12개, OCR 동시 실행 1개를 유지한다. 로그인·가입 시도 제한과 사용자별 기록 분리도 유지한다. AI 프롬프트·모델·품질 검증 단계는 변경하지 않는다.

API 사용료와 제공자의 사용 한도는 별개다. 화면의 작업 수는 토큰이나 비용이 아니며 실패·취소한 작업도 시작됐다면 포함한다. 개인정보 가림·OCR, 생략되거나 캐시에서 반환한 공식 안내는 AI 작업 수에 포함하지 않는다.

검증 결과는 [최종 운영 점검](../FINAL-PILOT-CHECK.md)에 기록한다.
