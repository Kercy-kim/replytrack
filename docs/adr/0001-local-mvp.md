# ADR 0001 — 3일 시연을 위한 로컬 단일 사용자 MVP

- 상태: 채택
- 후속 변경: [ADR 0030](0030-password-protected-presentation-hosting.md)에서 학교 PC 시연용 비밀번호 보호 배포를 추가했다. 일반 사용자별 기록 분리는 포함하지 않는다.
- 후속 변경: [ADR 0012](0012-web-operations-and-local-masking.md)에서 전송 전 개인정보 보호를 위해 로컬 OCR 의존성 설치를 추가했다. 아래 내용은 최초 MVP 결정이다.
- 날짜: 2026-11-14
- 관련 작업: [#1](https://github.com/Kercy-kim/replytrack/issues/1)

## 배경

문서만 있는 저장소에서 3일 안에 상담 입력 → 질문 분석 → 재문의 → 새 답변 반영을 시연해야 한다. 실행 환경에는 Node.js 24가 있으며 npm 명령은 기본 PATH에서 사용할 수 없다. 프로젝트 README의 5주 계획은 과제 기획 일정으로 유지한다.

## 결정

외부 패키지 없는 Node.js HTTP 서버, 내장 SQLite, 빌드 없는 HTML/CSS/JavaScript 화면을 사용한다. 서버는 127.0.0.1에만 바인딩한다. OpenAI Responses API는 서버에서 호출하고 키를 응답·로그·상담 DB에 기록하지 않는다. 화면에서 등록한 키는 메모리에만 보관한다.

JSON 스키마로 응답 구조를 고정하되 모델 출력을 그대로 신뢰하지 않는다. 질문은 소비자 메시지, 답변·약속은 업체 메시지에 연결하고 실제 부분 문자열인지 검증한다. 질문별 사용자 수정과 약속의 실제 확인은 서버에서 관리한다. 추가 답변을 먼저 저장하고 AI 분석은 별도 요청으로 처리한다. SQLite 레코드 버전으로 늦은 응답의 덮어쓰기를 방지한다.

예제 모드는 실제 AI 모드와 구분하여 표시한다. 예제는 준비된 두 개의 후속 답변만 사용하고 자유 입력은 실제 AI 상담에서 처리한다.

## 결과와 범위

별도 설치 없이 실행 가능하며 핵심 상태 전이를 테스트할 수 있다. 로그인·다중 사용자·서버 배포·주기 알림은 후속 범위다. 공개 배포 전에는 인증과 사용자별 데이터 분리, 업로드 보관 정책, 요청 제한, 비용 제한을 새 설계로 다뤄야 한다. 로컬 데이터베이스는 암호화하지 않는다.
