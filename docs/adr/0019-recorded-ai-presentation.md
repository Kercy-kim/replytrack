# ADR 0019 — 실제 AI 결과와 발표 시간의 분리

- 상태: 채택
- 날짜: 2026-11-15
- 관련: ADR 0018의 준비된 예제는 체험용으로 유지한다.

과제의 핵심 기능·구현 결과 발표를 강화하기 위해, 실제 API 실행 결과를 30초 동안 설명할 수 있는 읽기 전용 화면을 별도로 제공한다. 이는 실시간 생성 화면을 가장하거나 예제 데이터를 실제 모델 결과로 표시하는 변경이 아니다.

1. 기존 합성 계정 복구 자료를 실제 서비스 API 경로로 실행하고, 초기 분석·한국어 설명·업체 요청·영어 초안과 후속 답변·갱신 결과를 같은 기록에 보존한다.
2. 지정 합성 입력과 결과의 무결성을 검증한 뒤 표시용 JSON을 생성한다. 임의의 사용자 상담을 정적 공개 파일로 내보내지 않는다. 실제 모델 문장은 편집하지 않는다.
3. 재생 화면은 현재 API 호출·저장·자동 발송 없이 네 장면을 보여 준다. 원본 출처·해시·모델·실제 작업 시간을 제공하고, 가상 입력의 사전 실행 결과라는 표시를 유지한다.
4. 5분 발표는 네 핵심 기능을 중심으로 하고 30초 시연을 그 안에 포함한다. 기존 부가 기능은 설명 필요 시 보조 자료로 활용한다.

검증: [발표 준비 검증](../PRESENTATION-READINESS.md). 메일함 연동·배포·사용자 평가 같은 미구현·미검증 범위를 완료로 표현하지 않는다.
