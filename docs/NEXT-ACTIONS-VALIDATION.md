# 환불·교환과 지금 내가 할 일 검증

검증일: **2026-11-15 (Asia/Seoul)**. Windows, Node.js 24, Chrome/Playwright 환경에서 가상 상담과 격리된 SQLite로 확인했습니다. 실제 소비자 자료를 사용하지 않았습니다.

## 변경 범위

README와 웹의 기본 예제를 환불·교환 상담에 맞췄습니다. 질문 확인표 상단에 업체 요청, AI 재문의·처리 결과 확인 제안, 업체 안내 대기를 구분하는 `지금 내가 할 일`을 추가했습니다. 업체 요청에는 원문, 조건, 수행 기한, 이후 수행·철회 안내를 표시합니다. 사용자 수행 표시는 저장·취소할 수 있으며 실제 환불 완료와 별개입니다.

기존 질문 분석·재문의·인계의 모델과 프롬프트는 바꾸지 않았습니다. 업체 요청 확인은 사용자가 별도로 실행하며 생성 1회와 의미 검토 1회를 요청합니다. 연결 사전 점검이 필요하면 별도 호출이 발생합니다. 실제 공급자의 응답 시간·토큰 사용량은 이번 검증에서 측정하지 않았습니다.

새 기능 테스트는 다음을 확인합니다.

- 업체 요청·AI 제안·업체 대기의 구분과 환불 예제의 후속 답변.
- 허위 인용, 잘못된 발화자, 원문 밖 기한·조건, 같은 요청의 중복 식별자 거절.
- 이후 메시지에 근거한 수행 안내와 업체 철회, 누락된 이전 요청의 보존.
- 사용자 수행 표시의 재추출·DB 재시작 후 유지, 새 요청과 기존 완료의 분리, 모호한 ID 재생성 시 중복 완료 방지.
- 새 대화 뒤의 오래된 목록 표시와 완료 차단, 최신 분석 전 AI 제안 숨김.
- 영업일·기준 날짜 미정의 과도한 날짜 확정 방지와 조건부 요청 보존.
- 검토 실패·공급자 오류·취소·동시 수정 시 이전 할 일·질문·약속·초안 보존.
- 실제 HTTP 작업 경로와 OpenAI 클라이언트의 스키마·ID 변환·직렬화. 공급자 응답은 테스트용으로 대체했습니다.

## 화면 검증

새 기능 브라우저 검증은 데스크톱과 **390px 모바일**에서 실행했습니다. 원문 이동, 수행·새로고침·취소, 한 질문의 재문의 연결, 실제 환불 확인과의 분리, Markdown 내려받기를 확인했습니다. 키보드 초점 표시와 가로 넘침을 검사하고 데스크톱·모바일 캡처를 직접 확인했습니다.

실제 웹 작업 프로토콜을 거쳐 추출 취소 → 의미 검토 거절 → 재시도 성공을 재현했습니다. 이때 저장된 초안과 저장 전 편집 중인 초안 모두 유지되었습니다. 기존 통합 검증에서는 AI 연결 점검, 단계·경과 시간, 새 답변 분석 취소, 실제 로컬 한국어·영어 OCR과 전화번호·주소 가림을 확인했습니다. 기존 스크립트의 중복 버튼 선택자는 접근 가능한 정확한 버튼 이름으로 수정했습니다.

브라우저 검증에는 `REPLYTRACK_PLAYWRIGHT_MODULE`에 Playwright 모듈 경로, `REPLYTRACK_CHROMIUM`에 Chromium/Chrome 실행 파일 경로가 필요합니다. 결과·화면 캡처는 Git에서 제외된 `.artifacts/next-actions/`에 저장됩니다. 기존 작업 검증의 저장 위치는 해당 스크립트를 참고합니다.
