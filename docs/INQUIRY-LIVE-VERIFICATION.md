## 범위와 확인 기준

실제 Chrome과 OpenAI `gpt-5-mini-2025-08-07`을 사용했다. 환불 대화와 영어 계정 복구 이메일은 가상 자료이며, 문의 등록부터 새 답변 반영, 재문의 생성·편집·저장·복사·새로고침까지 UI로 조작했다. 격리된 메모리 DB를 사용했으며 이메일 발송이나 실제 사용자 기록 변경은 하지 않았다.

- 환불: 금액은 답변 받음, 결제수단은 미답변, 예정일은 답변 대기. 새 답변으로 결제수단만 답변 받음으로 바뀌고, 예정일 안내 약속은 남아 있어야 한다.
- 영어 계정 복구: 제출 자료만 답변 받음에서 시작한다. 새 답변의 심사 기간을 반영해도 문의 번호는 미답변으로 남아야 한다. 거래 ID 수령 안내를 계정 복구 완료로 취급하지 않는다.
- 영어 설명에 비밀번호·인증 코드를 보내지 말라는 원문 조건을 보존하고, 업체 요청 확인에서는 거래 ID 제출 요청을 추출한다.
- 질문의 기대 상태를 사전에 고정하고, 원문 인용·질문 ID 유지·변경 비교·재문의 대상·편집 보존을 검사한다. 요약의 질문/대기/요청/결과 확인 건수는 저장된 결과 및 목록 응답과 대조한다.
- 새 메시지 이후 오래된 업체 요청은 현재 요약에 집계하지 않고, 한국어 설명과 요청 목록에는 이전 답변 기준임을 표시한다.

## 발견한 문제와 수정

문의 A에서 `대기 보기`를 누른 뒤 문의 B를 열면 A의 질문 필터가 남아 B의 질문 일부가 숨겨졌다. 별도 Chrome 회귀 시나리오에서 실제 값 `waiting`, 기대 값 `all`로 실패하는 것을 확인했다.

다른 문의를 열 때 질문 필터를 `모든 질문`으로 초기화했다. 같은 문의를 다시 불러오거나 결과를 갱신할 때는 사용자가 선택한 필터를 유지한다. AI 프롬프트, 모델, 분석·검증 로직은 변경하지 않았다.
