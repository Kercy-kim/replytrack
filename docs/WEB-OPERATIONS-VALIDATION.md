# 웹 연결 점검·진행·취소·개인정보 가림 검증

2026-11-14. 웹 기능 구현의 회귀·브라우저 검증이다. 이번에는 실제 OpenAI 유료 요청이나 기존 20건 AI 품질 평가를 재실행하지 않았다. 공급자 응답·지연·오류는 테스트용으로 통제하고, 로컬 OCR과 브라우저·서버·SQLite는 실제 구현을 실행했다.

## 검사 범위

| 대상 | 검증한 동작 |
| --- | --- |
| 연결 사전 점검 | 키 등록/실제 점검 구분, 상담 없는 짧은 요청, 성공 캐시·설정 변경 무효화, 키 없음·인증·한도·모델·네트워크 오류 구분, 키·공급자 진단 비노출 |
| 실제 진행 | 서버의 대화 읽기·분석·상태 경계 검토·초안 의미 검토·원문 검증·저장 단계와 경과 시간. 추정 진행률 없음 |
| 취소 | 요청·응답 본문 중단, 늦은 응답 저장 차단, 전체 작업 시간 제한, 이미 완료된 결과의 거짓 취소 방지, 취소 실패·상태 재확인·중복 접수 방지 |
| 기록 보존 | 대화 읽기 취소 시 텍스트, 캡처 취소 시 텍스트·첨부파일, 첫 분석 취소 시 저장된 메시지, 추가 답변 분석 취소 시 기존 질문·약속·초안, 초안 검토 취소 시 DB와 미저장 편집 유지 |

| 외부 전송 | 원문·수정 지침 마스킹, 기존 인용의 요청별 로컬 복원, 원본 이미지 직접 전송 차단, 로컬 OCR 결과의 마스킹, 미리보기까지 AI 호출 없음 |
| 웹 화면 | Chrome 1440px·390px, 단계·시간 표시, 취소 후 재시도, 모바일 가로 넘침 없음, 브라우저 JS 오류 없음 |

## 실행 방법과 결과

```powershell
npm ci
node --test
node scripts/check.mjs
```

전체 자동 테스트 **109개 통과**, JavaScript **60개 파일 구문 검사 통과**. 기존 상담 상태·근거·인계 검증을 포함한다. 새 테스트는 `privacy.test.mjs`, `operations.test.mjs`, `web-operation.test.mjs`에 있다.

```powershell
# 별도로 설치된 Playwright 모듈과 Chromium/Chrome 실행 파일 경로를 환경변수로 지정
node scripts/check-web-operations.mjs
```

`REPLYTRACK_PLAYWRIGHT_MODULE`, `REPLYTRACK_CHROMIUM`을 지원한다. 실제 Chrome의 **5개 통합 흐름 통과**. 한국어 상담·전화번호·주소가 있는 가상 이미지를 로컬에서 생성하고 실제 한국어/영어 OCR을 실행했다. 원문 이미지나 개인정보가 들어 있는 외부 AI 요청은 없으며 브라우저의 외부 요청·JS 오류도 없었다. 스크린샷과 결과 JSON은 Git 제외 경로 `.artifacts/web-operations/`에 생성한다. 390px 검사는 브라우저 뷰포트 검사이며 실제 휴대기기 검사는 아니다.

## 범위의 한계

자동 가림은 모든 개인정보나 OCR 오류를 검출하지 않는다. 테스트 이미지의 성공은 복잡한 대화 캡처 전반의 인식 정확도를 입증하지 않는다. 사용자는 전송 전에 가림 결과를 확인하며, 기본 규칙 밖의 개인정보는 직접 지운다. 기존 DB 원문을 소급 변경하지 않으므로 과거 기록·내보내기에는 개인정보가 남을 수 있다. 기존 AI 품질·속도 평가 수치를 이번 코드에서 새로 측정한 결과로 제시하지 않는다.
