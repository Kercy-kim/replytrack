## 1. ReplyTrack · 0:00–0:20

ReplyTrack은 바쁜 일상에서 고객센터 문의를 이어가도록 돕는 AI 웹 서비스입니다. 받은 답변과 남은 질문, 지금 해야 할 일을 정리하고 실제 해결 여부까지 확인하도록 만들었습니다. 개요와 AI 활용, 구현 결과 순서로 소개하겠습니다.

## 2. 문의를 다시 열었을 때의 불편 · 0:20–0:55

답장을 며칠 뒤에 확인하면 무엇을 물었는지부터 다시 읽게 됩니다. 여러 질문 중 일부만 답변받았거나, 추가 자료를 보내야 하는데 잊는 일도 있습니다. 영어 답변이라면 조건을 이해하는 부담까지 생깁니다. 대상은 쇼핑, 구독, 계정 문제로 여러 번 문의하는 일반 사용자입니다. ReplyTrack은 남은 질문과 할 일, 기다리는 처리를 한 기록에 정리해 문의를 이어가도록 돕습니다.

## 3. 기존 서비스와 개선점 · 0:55–1:30

Gmail의 Gemini는 이메일 요약과 답장 작성을, NoReply는 사례 맥락을 활용한 AI 대화와 다음 대응 안내를 제공합니다. ReplyTrack은 질문마다 충분한 답변을 받았는지 추적하고, 새 답변으로 바뀐 부분을 원문 근거와 연결합니다. 또 업체가 처리했다고 안내한 상태와 사용자가 실제 해결을 확인한 상태를 나눕니다. 이는 구현한 사용 흐름의 개선점이며, 경쟁사에 없는 유일한 기능이나 성능 우위를 주장하는 것은 아닙니다.

## 4. 핵심 기능 네 가지 · 1:30–2:20

핵심 기능은 네 가지입니다. 첫째, 질문별로 답변 받음, 부분 답변, 미답변 같은 상태와 원문 근거를 보여 줍니다. 둘째, 지금 내가 할 일을 정리합니다. 거래 ID를 제출하는 사용자 행동과 심사를 진행하는 업체의 일을 구분합니다. 셋째, 영어 답변의 조건과 금지 사항을 한국어로 설명하고, 선택한 남은 질문만 영어 초안으로 만듭니다. 넷째, 새 답변을 반영하면 같은 질문과 약속의 이전 상태와 현재 상태를 비교합니다. 자료가 접수됐다는 답변을 받아도 실제 계정 복구를 완료 처리하지는 않습니다.

## 5. AI가 해석하고, 코드가 검증·기록 · 2:20–3:00

입력은 이메일 본문이나 상담 캡처입니다. 캡처는 로컬 OCR로 읽고 사용자가 발신자와 원문을 검토합니다. OpenAI 모델은 질문과 답변의 의미, 조건, 행동 주체를 해석하고 한국어 설명과 영어 초안을 생성합니다. 단순 키워드만으로는 접수, 심사 예정, 실제 복구 완료를 구분하기 어렵기 때문에 AI를 사용합니다. 서버는 원문 인용을 확인하고 AI 의미 검토도 수행합니다. 저장과 날짜 계산, 전후 차이 계산은 일반 코드가 담당하며, 실제 해결은 사용자가 확인합니다.
