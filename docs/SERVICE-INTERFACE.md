# 실제 문의 중심의 화면 정리

2026-11-16. 사용자가 실제 문의를 등록하고 관리하는 흐름에 집중하도록 기본 화면을 정리했다.

- 첫 화면의 ‘예제로 먼저 둘러보기’와 메뉴의 이메일·환불 예제 생성 버튼을 제거했다. ‘내 문의 정리하기’는 실제 등록 입력창을 연다.
- 일반 메뉴에서 발표 링크를 제거했다. 발표용 결과 재생은 `http://127.0.0.1:3100/presentation` 주소로 직접 연다.
- ‘워크스페이스’를 ‘내 문의’로, 저장 위치 안내를 ‘문의 기록은 이 기기에 저장돼요’로 바꿨다. 기존 디자인과 문의 등록·분석 기능은 유지했다.
- 기존 가상 기록은 삭제하지 않는다. 목록·상세·내려받기에 ‘가상 기록’을 표시하고 준비된 데이터임을 밝힌다. 호환용 생성 API와 기존 기록 재생은 유지하되 일반 화면에서 새로 생성하지 않는다.

## 확인 결과

자동 테스트 275개, 문법 142개 파일, Chrome 회귀 9종을 통과했다. 이번 변경은 화면과 문서이며 AI 프롬프트·분석·저장 로직은 바꾸지 않았다. 유료 API 품질 평가는 이번에 반복하지 않았다.

화면 검사는 320·390·768·1280·1440px에서 가로 넘침과 등록 진입, 입력 보존, 답장 편집·복사·저장, 삭제 취소, 기존 기록의 가상 데이터 표시를 확인했다. 1280px와 390px 첫 화면의 실제 렌더링도 확인했다. 발표 화면 네 장면과 기존 이메일 기록 재생도 통과했다.

첫 UI 검사에서는 안내 문구의 줄바꿈을 허용하지 않은 테스트 정규식이 실패했다. 줄바꿈을 허용하도록 검사만 수정한 후 해당 Chrome 검사를 다시 실행해 통과했다. 첫 실행과 재검사 결과를 [검증 집계](../evals/results/presentation/service-interface-checks.json)에 구분했다.

서비스 중심의 화면 정리이며 외부 배포나 다중 사용자 운영을 완료했다는 뜻은 아니다.
