# 핵심 흐름과 가독성 개선

2026-11-15. 현재 main을 기준으로 가상 상담과 메모리 DB를 사용해 Chrome에서 점검했다. 이번 변경은 웹 표현과 탐색 경로이며 AI 프롬프트·분석 결과·API 호출 수를 바꾸지 않는다. 실제 사용자 효과 평가나 새로운 실제 API 품질 평가로 해석하지 않는다.

## 발견한 불편과 보완

| 발견한 불편 | 적용한 개선 |
| --- | --- |
| 예제·발표·SSG 버튼이 기본 탐색을 차지하고 모바일에서 내용이 아래로 밀림 | 새 상담·전체 보기를 먼저 두고 보조 기능은 `예제 · 도움 기능`에 모음. 키보드로 펼칠 수 있고 다시 렌더링해도 선택 유지 |
| 원문·판정 이유가 모바일에서 12px, 질문 제목이 13px로 작음 | 주요 읽기 본문 15px, 질문·약속 제목 16px, 폼 입력 16px. 상태색·원문 근거는 보존 |
| 재문의 제안과 업체 대기 내용이 아래 질문·약속 목록과 반복됨 | 중복 상세를 건수 있는 접힘 영역으로 제공. 업체 요청과 실제 결과 확인은 바로 표시 |
| 인계가 재문의와 나란히 보여 기본 행동이 분산됨 | `답장 작성`에서 재문의 우선, 인계는 `다른 상담원에게 전달할 요약`에서 펼침. 생성·편집·복사 기능 유지 |
| 텍스트 입력에도 캡처 언어와 파일 옵션이 항상 표시됨 | `캡처로 가져오기 (선택)`에 묶음. 파일 선택·OCR·입력 복원 유지, 이메일에 맞는 입력 예시 제공 |
| 모든 질문에 답변받아도 재문의 유도 버튼이 남음 | 해당 버튼 숨김. 질문 답변 수신과 별개인 실제 처리 확인은 유지 |
| 상세 상단의 X 아이콘이 닫기로 오인될 수 있음 | 삭제를 상담 관리 안의 명시적인 버튼으로 이동. 최종 확인·취소와 보관 기능 유지 |

핵심 기능을 삭제하거나 원문·판정 결과를 축약하지 않았다. 사용 빈도가 낮거나 반복되는 화면만 접었으며, 펼친 상태는 브라우저 탭 메모리에 보관한다. 사용자 원문을 새로 브라우저 저장소에 넣지 않는다.

## 검증

- `node --test`: 202개 통과. 최초 제한 환경에서 발생한 로컬 HTTP 연결 EACCES는 로컬 연결을 허용한 실행에서 해소됨.
- `node scripts/check.mjs`: JavaScript 106개 문법 검사 통과.
- `scripts/check-ui-refinement.mjs`: 320·390·768·1280·1440px, 가로 넘침, 주요 글자 크기, 키보드 메뉴, 펼친 상태 유지, 인계 편집 보존, 삭제 취소, 답변 완료 후 행동, 이메일 입력 복원 확인.
- `scripts/check-email-browser.mjs`: 본문·실제 로컬 OCR 입력, 한국어 설명, 영어 초안, 새 답변 비교, 이전 설명 갱신, 재접속 확인.
- `scripts/check-next-actions.mjs`: 원문 이동, 수행 확인·취소·재접속, 특정 질문 재문의, 처리 결과 확인, 취소·오류 시 초안 보존 확인.
- `scripts/check-web-operations.mjs`: 연결 점검, 입력 가림, 실제 로컬 OCR, 작업 취소·복구, 저장·미저장 초안 보존의 5개 흐름 확인.
- `scripts/check-email-demo.mjs`, `scripts/check-presentation.mjs`, `scripts/check-official-guide.mjs`: 보조 메뉴 접근 경로와 기존 시연·안내 흐름 확인.

브라우저 검사는 실제 Chrome과 가상 AI 응답을 사용하며 유료 OpenAI 호출은 하지 않는다. 발표 화면은 기존 실제 API 기록을 재생한다. SSG 검사에는 공식 검색 경로 검증이 포함되나 AI 응답은 가상이다. 휴대폰 실기기·전체 접근성 인증·모든 입력에서의 품질 검증은 아니다.

재현 시 기존 브라우저 설치 경로를 `REPLYTRACK_PLAYWRIGHT_MODULE`, `REPLYTRACK_CHROMIUM`에 설정한다. 결과와 화면은 Git 제외 경로 `.artifacts/ux-refinement/` 및 각 검사 스크립트의 기존 경로에 저장한다.
