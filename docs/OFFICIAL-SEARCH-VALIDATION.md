# 공식 안내 자동 검색 검증

검증일: 2026-11-17

## 구현

기존 SSG·Google·Microsoft·Apple 연결 자료는 그대로 사용한다. 그 외 문의처는 OpenAI 웹 검색으로 공식 고객지원·정책 페이지를 찾는다. 검색에는 업체명과 제한된 공개 질문 주제만 전달하며, 문의 원문·계정 정보·주문 번호는 검색어로 전달하지 않는다.

검색 도구가 실제 반환한 URL만 후보로 인정하고 서버가 HTML 본문을 직접 읽는다. 출처의 공식성, 질문·제품·지역·조건의 일치, 원문 근거, 상담 답변과의 충돌 여부를 별도로 검토한다. 정확한 원문 인용·링크·조회 날짜를 표시하고 검토 실패, 본문 조회 실패, 시간 초과는 생략한다. 검색만으로 개인 환불·복구 완료 시점을 확정하지 않는다.

등록된 서비스 목록 밖에서도 검색할 수 있지만 모든 사이트나 주제를 보장하지 않는다. 공개 정책 주제에 해당하지 않거나 로그인·접근 차단·리디렉션 등으로 본문을 확인할 수 없으면 안내가 나타나지 않을 수 있다.

HTTPS 공개 주소만 읽고 DNS 결과를 고정한다. 사설·예약 IP, 자격 증명 포함 URL, 리디렉션, 비 HTML, 과대 응답을 차단한다. 조회는 문의 분석·답장 작성과 독립적으로 진행하며 기존 질문 판정·상담 기록을 수정하지 않는다. 결과는 30분 캐시하며 동시 조회는 2개로 제한한다.

## 실제 OpenAI 평가

최종 코드 5건 평가에서 기대한 표시/생략 결과는 4건 일치했다. 전체 성공으로 기록하지 않는다.

| 사례 | 실제 결과 | 소요 시간 | 검토 |
|---|---|---:|---|
| Netflix 해지 후 남은 이용 기간 | 공식 도움말 표시 | 40.0초 | 남은 기간·보류 계정 예외 확인 |
| Adobe 한국 연간 월별 결제, 14일 이후 취소 수수료 | 생략 | 49.0초 | 원문에 해당 수수료 기준이 없어 표시 기대 미달 |
| Spotify 해지 후 플레이리스트 유지 | 공식 도움말 표시 | 57.8초 | 계정 삭제와 혼동 없이 목록 유지 안내 |
| Netflix 개인 환불의 오늘 오후 3시 입금 확답 | 생략 | 6.2초 | 공개 정책으로 개인 결과 확정 불가 |
| 식별할 수 없는 가상 업체 | 생략 | 11.3초 | 공식 출처 확보 불가 |

Adobe 안내를 억지로 표시하도록 검증을 완화하지 않았다. 이전 반복 평가에서 일반적인 14일 이내 환불 설명이 표시된 적도 있어, 평가 결과를 읽을 때 표시 여부뿐 아니라 실제 질문에 답하는지 확인해야 한다. 최종 실행에서는 검토 단계가 근거 부족을 감지하여 생략했다. 위 시간은 부가적인 공식 안내 완료 시간이며 최초 문의 분석 시간이 아니다.

원시 결과는 로컬 `.artifacts/official-search-final/result.json`에 보관한다. 실제 웹 검색과 모델 응답은 실행 시점에 따라 달라진다.

## 자동·화면 검사

- 전체 자동 테스트 298개 통과, JavaScript 156개 구문 검사 통과.
- 검색 도구에 없는 URL, 허위 인용, 불명확한 공식 출처, 질문 불일치, 취소·실패 시 생략 검증.
- 실제 Chrome에서 자동 조회, 공식 링크, 390px/1280px 가로 넘침 없음, 작성 중 초안 보존, 상담 기록 불변 검증.
- 화면 검사의 저장된 문의 분석은 fixture이며 공식 검색·본문 조회·생성·검토는 실제 API다. 최초 분석 전체 품질 재평가로 해석하지 않는다.
- PPT/PDF 7페이지의 고정 지원 업체 문구를 제거하고 자동 검색·검토 흐름으로 변경. 내장 영상은 보존.
