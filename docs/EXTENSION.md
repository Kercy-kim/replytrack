# ReplyTrack Chrome 확장 프로그램

기존 웹을 유지하면서 선택한 고객센터 대화를 Chrome 옆 패널로 가져오는 로컬 MVP입니다. **Chrome 116 이상**, **Node.js 24 이상**이 필요합니다. 확장 프로그램과 서버는 같은 컴퓨터에서 실행합니다.

## 설치와 실행

1. 이 브랜치의 프로젝트 폴더에서 `node server.mjs`를 실행합니다.
2. `http://127.0.0.1:3100`을 열고 **AI 연결 설정**에서 API 키를 등록합니다. 이미 `.env`에 키가 설정되어 있다면 이 단계는 생략합니다. 확장 프로그램에는 키를 넣지 않습니다.
3. Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 눌러 프로젝트의 **`extension` 폴더**를 선택합니다. 저장소 전체 폴더가 아닙니다.
5. Chrome 확장 메뉴에서 ReplyTrack을 고정합니다.

별도 빌드·패키지 설치·스토어 등록은 필요하지 않습니다. 확장 프로그램을 수정한 뒤에는 확장 관리 화면에서 새로고침하고 패널을 다시 엽니다. 서버 코드를 수정했다면 서버도 재시작합니다.

## 사용 순서

1. 웹페이지에서 **내 질문과 고객센터 답변을 함께** 드래그합니다.
2. ReplyTrack 아이콘을 누르거나, 선택 영역에서 **우클릭 → ReplyTrack으로 선택한 대화 가져오기**를 누릅니다.
3. 옆 패널의 가져온 내용을 확인합니다. 직접 붙여넣거나 불필요한 내용을 지울 수 있습니다. 최대 30,000자입니다.
4. **대화 읽기**를 누릅니다. 이 시점에만 선택한 텍스트를 서버를 통해 OpenAI로 전송합니다.
5. AI가 나눈 발화자와 원문을 수정한 뒤 **확인한 대화 분석하기**를 누릅니다. 발화자가 불명확하면 직접 선택합니다. 날짜가 잘못 인식되었으면 날짜 미정으로 변경합니다.
6. 질문별 답변 상태·판단 이유를 읽고 **판단에 사용한 원문 보기**로 인용을 확인합니다.
7. 재문의할 질문의 체크박스를 선택하고 **재문의 초안 만들기**를 누릅니다. 초안을 편집하고 **초안 복사**로 가져갑니다. 자동 발송하지 않습니다.
8. **웹에서 기록·수정**을 누르면 같은 상담이 웹에서 열립니다. 후속 답변 추가, 질문 판정 수정, 실제 처리 확인은 기존 웹에서 진행합니다. 패널의 **새로고침**으로 최신 결과를 불러옵니다.

새 선택을 가져와도 편집 중인 대화나 초안을 자동으로 바꾸지 않습니다. 패널의 **선택한 대화로 바꾸기**를 눌러 전환합니다. 다른 대화를 분석해도 이미 저장한 상담은 웹 기록에 남습니다.

웹에서 **편집 저장**한 재문의 초안은 패널을 새로고침하거나 다시 열면 표시됩니다. 패널에서 직접 편집 중인 내용이 있으면 그 내용을 유지하고, 웹 기록이 변경되었다는 안내를 표시합니다.

## 시연하기

웹에서 **예제 상담 열기**를 누른 다음 원문의 내 질문·고객센터 답변을 선택해 확장으로 가져올 수 있습니다. 웹의 예제는 고정된 가상 자료지만, 확장의 **대화 읽기·분석·초안 작성은 실제 AI API를 호출**합니다. 확장에는 고정 결과를 반환하는 예제 모드가 없습니다.

예상 흐름: 수리비는 답변 대기, 수리 기간은 답변 받음, 배송비는 미답변 → 배송비 질문 선택 → 재문의 생성 → 웹에서 같은 기록 확인. 모델 응답은 실행마다 달라질 수 있습니다.

## 연결과 지원 범위

- 서버 주소는 `http://127.0.0.1:3100`으로 고정합니다. 서버를 끄면 확장의 분석도 중단됩니다.
- 서버 연결 오류: `node server.mjs` 실행 여부와 포트를 확인하고 **연결 확인**을 누릅니다.
- AI 설정 필요: 웹의 **AI 연결 설정**에서 키를 등록하고 다시 확인합니다. 서버 메모리에만 넣은 키는 서버를 재시작하면 다시 등록합니다.
- 채팅창이 별도 프레임에 있어 아이콘으로 읽히지 않으면 **선택 영역에서 우클릭 메뉴**를 사용합니다. 그래도 안 되면 직접 붙여넣습니다.
- 브라우저 설정 페이지, PDF 뷰어, 별도 데스크톱·모바일 앱, 선택할 수 없는 이미지 대화의 자동 읽기는 지원하지 않습니다. 이미지 입력은 기존 웹에서 사용할 수 있습니다.
- 페이지 전체 자동 수집, 사이트별 자동 인식, 새 답변 실시간 감지, 자동 발송, 계정 동기화는 이번 범위에 없습니다.
- 분석 오류가 나도 먼저 저장한 원문은 유지됩니다. **저장한 원문 다시 분석**으로 재시도합니다. 다른 창에서 상담을 바꾸면 최신 기록을 불러온 뒤 진행합니다.

## 데이터와 권한

- `activeTab`·`scripting`: 사용자가 실행한 탭에서 선택한 텍스트를 읽습니다. 상시 콘텐츠 스크립트는 없습니다.
- `contextMenus`·`sidePanel`: 우클릭 가져오기와 옆 패널을 제공합니다.
- `storage`: 브라우저 창별 입력·검토 내용·편집 초안을 `storage.session`에 보관합니다. 패널을 닫았다 열어도 복구되지만 브라우저 종료·확장 다시 로드 시 사라집니다. 동기화 저장소를 쓰지 않습니다.
- `clipboardWrite`: 사용자가 누른 초안 복사 기능에 사용합니다.
- 호스트 권한: `http://127.0.0.1/*`만 요청합니다. Chrome 호스트 권한은 포트 단위로 제한할 수 없으며 실제 요청 주소와 CSP는 3100 포트로 고정합니다.
- 원본 페이지 URL의 경로·쿼리·해시를 저장하거나 AI로 보내지 않습니다. 제목과 호스트명은 패널의 가져온 곳 안내에만 사용합니다.
- 확인한 상담 원문·분석·생성 초안은 기존 로컬 SQLite에 저장합니다. **패널에서 직접 편집한 내용은 브라우저 세션에만 유지**되며 웹에 자동 반영하지 않습니다. 웹에서 기록이 바뀌거나 재분석해도 편집한 초안을 보존하고 최신 답변과 대조하라는 안내를 표시합니다. **다시 작성** 또는 **다른 대화 분석**을 직접 선택할 때만 편집 내용을 교체합니다.
- manifest의 `key`는 개발 중 확장 ID를 고정하는 **공개키**이며 API 비밀키가 아닙니다. 서버는 이 ID의 출처와 필요한 API 경로·메서드만 허용합니다. 이 출처 검사는 사용자 인증을 대체하지 않습니다. 서버는 계속 127.0.0.1에서만 실행합니다.

## 검증

`node --test`와 `node scripts/check.mjs`를 실행합니다. 확장 테스트는 선택 영역·길이 제한·출처 검사·CORS 사전 요청·입력부터 초안까지의 API 흐름·분석 실패 후 원문 보존·기존 웹 접근을 확인합니다. 테스트의 AI 응답은 결정적 가상 응답이며 AI 정확도 평가가 아닙니다.

브라우저 검증은 `scripts/check-extension-browser.mjs`로 실행합니다. 별도 Playwright와 확장을 지원하는 테스트용 Chromium 경로가 필요하며 환경변수는 스크립트 상단을 참고합니다. 실제 프로필 대신 `.artifacts/extension-browser-profile`을 사용하고, 메모리 DB와 테스트 AI로 동작합니다. 3100 포트가 비어 있어야 합니다. 완료 후 테스트 브라우저와 서버를 종료합니다.
