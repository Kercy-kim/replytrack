# 최신 UI에서 실제 API 웹 흐름 검증

2026-11-15, main `05481f4`를 기준으로 실제 Chrome과 OpenAI API를 사용했다. 입력은 가상 환불 문의와 영어 계정 복구 이메일이며 메모리 DB에서 실행했다. 실제 메일을 읽거나 발송하지 않았다. 관측 모델은 `gpt-5-mini-2025-08-07`이다.

## 확인한 흐름

| 사례 | 처음 분석 | 새 답변 반영 | 재문의 결과 |
| --- | --- | --- | --- |
| 환불 | 환불 금액 답변 받음, 결제수단 미답변, 환불 예정일 답변 대기 | 원결제 카드로 환불한다는 답변 반영. 결제수단만 답변 받음으로 변경하고 예정일은 대기 유지 | 남은 환불 예정일만 묻는 한국어 초안 |
| 영어 계정 복구 | 제출 자료 답변 받음, 검토 기간·문의번호 미답변 | 검토 기간 3영업일을 반영하고 문의번호는 미답변 유지 | `Please provide my case reference number.` |

두 사례 모두 본문 입력 → 개인정보 가림 미리보기 → 원문·발화자 확인 → 분석 → 새 답변 추가 → 이전/이후 비교 → 재문의 생성 → 직접 편집 → 저장·실제 클립보드 복사 → 새로고침 후 유지까지 통과했다. 질문 ID와 원문 근거가 유지되고, 업체 안내만으로 실제 환불·계정 복구를 완료 처리하지 않는 것도 확인했다.

영어 이메일은 한국어 설명과 제출할 자료 추출도 실제 API로 확인했다. 거래 ID 제출 요구와 비밀번호·인증 코드를 보내지 말라는 원문 조건이 보존됐다. 새 답변 뒤 기존 한국어 설명에는 이전 답변 기준임을 표시했다.

## 발견한 불편과 수정

영어 이메일의 발화자를 AI가 `확인 필요`로 추출한 경우, 저장을 시도한 뒤 오류를 읽고 선택란을 찾아야 했다. 확인할 메시지 수와 선택 방법을 미리 표시하고, 저장 시 첫 미확인 발화자로 포커스와 스크롤을 이동하도록 보완했다. 확인 전에는 저장이나 추가 분석 요청이 시작되지 않는다. 선택·삭제 시 안내를 갱신한다. AI가 모호하게 추출한 발화자를 자동으로 고객센터로 단정하지 않는다.

생성·분석 프롬프트와 모델 설정은 변경하지 않았다. 데스크톱과 390px 모바일 화면에서 원문 확인, 비교 결과, 초안 편집 화면을 점검했다.

## 시간과 검증 범위

아래는 브라우저 클릭·서버 처리까지 포함한 단일 실행 시간이다. 평균이나 성능 보장이 아니다.

| 흐름 | 환불 | 영어 이메일 |
| --- | ---: | ---: |
| 등록·분석 | 31.30초 | 28.78초 |
| 한국어 설명·할 일 추출 | 해당 없음 | 29.28초 |
| 새 답변 반영·비교 | 19.28초 | 29.24초 |
| 재문의·편집·저장·복사·재접속 | 12.88초 | 7.87초 |

- 실제 API: 위 가상 사례 2건. 1280px·390px 화면, 질문 상태·근거·실제 처리 미확정·초안 저장과 복사 확인. 브라우저 JavaScript 오류 없음.
- `node --test`: 202개 통과.
- `node scripts/check.mjs`: JavaScript 107개 문법 검사 통과.
- `scripts/check-email-browser.mjs`: 가상 AI로 미확인 발화자 안내·포커스·분석 차단, 본문·실제 로컬 OCR, 한국어 설명, 영어 초안, 답변 비교·갱신·재접속 회귀 검사 통과.
- `scripts/check-web-operations.mjs`: 가상 AI로 연결 점검, 개인정보 가림, 취소·재시도, 저장·미저장 초안 보존, 실제 로컬 OCR 등 5개 흐름 통과.

이번 실행은 배송·환불·구독 48건 전체 재평가가 아니다. 모바일 실기기나 모든 이메일 형식에서의 품질을 보장하지 않는다. 실제 API 대기 시간이 있으므로 전체 흐름을 30초 안에 완료했다고 설명하면 안 된다.

## 실행 기록과 재현

[실행 기록](../evals/results/live-browser/validation.json)에 성공 사례의 입력·상태·초안·시간·호출 토큰과 초기 검사 중단 이유를 보존했다. 원시 기록·스크린샷은 `.artifacts/live-browser/<실행 시각>/`에 남긴다. 모든 입력은 합성 자료이며 API 키는 기록하지 않는다.

초기 검사 도구에는 존재하지 않는 초안 사용량 필드를 읽는 오류, Windows 클립보드 줄바꿈 비교 오류, AI가 항상 발화자를 확정한다는 잘못된 가정이 있었다. 이를 고쳐 다시 실행했다. 환불은 `2026-11-15T12-22-50-125Z` 실행의 환불 사례 전체가 통과했고, 같은 실행의 이메일은 발화자 가정에서 중단됐다. 이메일은 사용자 발화자 확인 흐름을 적용한 `2026-11-15T12-25-01-667Z` 실행 전체가 통과했다. 중단 실행을 전체 성공으로 계산하지 않았다.

로컬 `.env`에 API 키를 설정하고 `REPLYTRACK_PLAYWRIGHT_MODULE`, `REPLYTRACK_CHROMIUM`을 설치된 모듈·Chrome 경로로 지정한 뒤 실행한다. 유료 API 호출이 발생한다.

```powershell
node scripts/check-live-browser.mjs --run
# 한 사례만 실행
node scripts/check-live-browser.mjs --run --case=email
```
