# 영어 새 답변 최적화와 발표 핵심 범위

2026-11-15. 시작 main: `1cb1d96140382c415280320beb21ae230db60c68`. 구현 결정은 [ADR 0022](adr/0022-presentation-core-focus.md)에 기록한다.

## 관측 원인과 변경

기존 실제 Chrome 기록의 영어 새 답변 반영은 31,847ms였다. 이메일 전사 4,624ms, 질문 분석 25,332ms가 대부분을 차지했다. 브라우저 조작·폴링도 전체 시간에 포함된다. 모델 추론·응답 생성이 주 지연 단계이며 공급자 내부 지연 원인을 단정할 자료는 없다.

새 고객 질문이 없는 이메일에 한해 이미 확정된 질문 제목·원문을 다시 생성하지 않는다. 단순·짧은 문맥에만 low 추론을 적용하고 원문 전체, 현재 질문·약속, 의미 판정·원문 검증은 유지한다. 조건·정정·긴 이메일과 분석 수정·별도 검토는 medium이다. 질문 연결 실패는 전체 스키마로 수정한다. 기존 이메일 평가 중 떨어진 두 원문 문장을 하나로 인용해 두 차례 검증에 실패한 사례를 발견했다. 이를 정확한 개별 인용으로 분리하되 변형된 단어·순서·발화자는 계속 거절한다.

분석 실험은 같은 합성 원문·기존 질문을 고정하고 기존 medium 전체 출력과 compact low 후보를 교대로 호출했다. 기존 24.0/30.0/39.8초, 후보 8.6/11.0/12.2초였다. [원본 비교](../evals/results/email-reply/comparison.json)는 통합 전 후보 실험의 코드 해시를 포함한다. 후보 3/3이 엄격한 질문·약속 검사에 통과했고 기존 경로 1회는 일반 심사 기간을 별도 약속으로 만들어 실패했다. 이 실패를 제외하지 않고 시간 평균에 포함했다. 비교 스크립트는 통합 후에도 기존 생성 파라미터를 명시적으로 재현한다.

실제 웹의 최종 실행에서는 첫 분석 6.7초 뒤 처리 통보 누락 검토 9.0초가 추가돼 전체 반영은 21.4초였다. 검토를 없애서 얻은 수치가 아니다. 분석 단계 실험의 토큰 절감을 전체 화면 사용 비용 절감으로 확대하지 않는다. 취소한 보조 요청의 사용량이 알려지지 않으면 기록한 토큰은 전체 과금의 하한이다. 네트워크·모델 변동과 작은 표본 때문에 항상 이 시간 안에 끝난다고 보장하지 않는다.

## 품질·브라우저 검증

- 최종 `node --test` 232/232, JavaScript 113개 구문 검사 통과. 제거한 확장 테스트를 제외하고 새 이메일·공식 안내·원문 보존·최대 수정 횟수·외부 출처 차단 검사를 포함한다.
- 새 답변용 영어 가상 사례 20/20 통과: 답변 받음·미답변·부분 답변·대기·확인 필요, 처리 약속·통보, 질문 ID·원문·직접 확인 분리. 이 평가는 초기 분석을 가장한 실제 API 평가가 아니라 준비된 질문 상태에 새 업체 답변을 반영하는 평가다. [최종 기록](../evals/results/email-reply/validated.json).
- 최초 20건에서 ‘환불 수단 답변’을 별도 처리 약속 1개로 기대한 평가 기준을 0개로 바로잡았다. 원문·제품 출력은 바꾸지 않고 전체 20건을 다시 실행했다. 최초 결과도 보존한다.
- 기존 계정 복구·조건부 환불 이메일 2건의 초기 분석·새 답변 반영 재평가 통과. 앞서 인용 결합으로 실패한 기록과 인용 분리 보완 후 [재평가](../evals/results/email-reply/existing-email-recheck.json)를 함께 보존한다.
- 실제 OpenAI + Chrome으로 환불·영어 문의의 등록, 새 답변 전후 비교, 요약 대조, 재문의 생성·편집·저장·복사·재접속 2/2 통과. [최종 웹 기록](../evals/results/email-reply/web-final.json). 이후 공식 안내 문구만 다듬었으며 영어 분석 경로는 이 실행과 같다.
- Chrome 기존 문의 요약·탐색·검색·필터, 320~1440px UI, 편집 보존·취소·원문 가림·로컬 OCR 회귀 통과. 공식 안내 전용 Chrome 검사도 320/390/1280px에서 비차단 조회, 늦은 결과 도착 시 초안 편집 유지, 공식 링크, 새 메시지 후 오래된 안내 숨김을 확인했다.

배송·환불·구독 48건의 기존 점수를 이번 변경 후 새로 실행한 수치로 인용하지 않는다. 일반 상담은 최적화 분기에 들어가지 않으며 이번 실제 API 평가는 영어·공식 안내와 두 웹 흐름에 집중한다.

## 발표·기능 범위

Chrome 확장 코드·설치 안내·전용 CORS 예외를 제거했다. 별도 SSG 질문 화면을 없애고 지원 문의처의 공식 본문을 자동 조회해 원문·조건 검토에 통과한 한 항목만 접힌 참고 영역으로 붙인다. SSG 일반 상품, Google·Microsoft·Apple 계정 복구를 지원한다. 모든 사이트나 모든 문의 종류를 검색·보증하는 기능은 아니다. 알 수 없는 문의처, 검색 실패, 근거 부족·조건 불명확·상담 답변과 충돌은 안내를 생략한다. 공식 일반 기준을 사용자의 실제 처리 결과로 저장하지 않는다.

공식 본문 실제 조회와 생성·검토 실행은 별도 결과 파일에 기록한다. 최초에는 Apple 질문에 묻지 않은 다른 대기 기간까지 덧붙인 결과가 있어 한 항목·실제 질문 범위로 좁혔다. 후속 실행에서 독립 검토가 거절한 안내는 화면에 게시되지 않았다. 공통 고지는 화면으로 옮겨 안내 본문은 실제 답에 집중하도록 했다.

관련성이 확인된 안내의 근거·조건 누락은 원문 피드백으로 한 번만 보완하고 다시 독립 검토한다(보통 2회, 수정 시 최대 4회 API 호출, 전체 60초 제한). 관련성·충돌 검토 실패는 수정으로 우회하지 않는다. [최종 공식 안내 평가](../evals/results/email-reply/official-context-verified.json)는 Google·Microsoft·Apple·SSG 4건의 실제 출처·API 안내와 미지원 업체 생략을 통과했다. Microsoft와 SSG는 조건 보완과 재검토 후 표시됐다. 공식 안내 자체는 별도 백그라운드 작업으로 이번 최종 실행에서 약 14~44초 걸렸다. 이를 새 답변 반영 21.4초에 포함하거나 전체 기능이 모두 빨라졌다고 주장하지 않는다.

발표는 **문제·목적·사용자와 상황 → 핵심 기능 네 개와 AI 역할 → 입력·처리·출력 → 30초 결과 시연** 순서를 유지한다. 핵심은 질문별 상태, 지금 내가 할 일, 한국어 설명·영어 재문의, 새 답변 비교다. 공식 안내는 보조 설명으로 제한하고 독립 챗봇·확장을 다시 추가하지 않는다.
