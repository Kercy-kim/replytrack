- 인계 요청 A를 지연시킨 상태에서 탭·B 상담·목록 이동, 복사 버튼 실행 및 성공 안내 확인. 인앱 브라우저의 자동화 가상 클립보드는 웹 클립보드와 공유되지 않아 붙여넣기 왕복 검증은 제외했다.
- B 화면에서 A 요청 완료: B 화면 유지. A로 돌아온 뒤 새로고침해도 A의 인계 결과가 남고 B에는 인계 초안이 생기지 않음.
- 목록 화면에서 다른 상담의 진행 중 요청 취소: 목록 유지와 취소 안내 확인.
- 생성 중 초안은 disabled가 아닌 readonly로 선택 가능하며 복사 버튼이 활성이다. 키보드 화살표로 분석 탭 전환도 확인했다. 원래 요청을 취소한 뒤 늦은 가상 응답을 풀어도 기존 초안은 유지됐다.

지연·연결·읽기·완료 경로는 별도의 메모리 DB와 가상 AI 응답으로 재현했다. 실제 OpenAI 품질·속도 평가 결과로 해석하지 않는다. 실제 앱 코드와 기존 검증/저장 경로를 사용했으며 운영 데이터, API 키와 테스트용 서버는 커밋하지 않았다.

## 입력 보존 범위

임시 입력은 현재 탭의 메모리에만 둔다. 브라우저 새로고침·종료를 승인하면 사라지며, 이를 막기 위한 이탈 경고를 표시한다. API 키는 임시 입력에 포함하지 않고, 선택한 캡처도 원본 파일 객체를 메모리에만 유지한다. 서버 저장 시 기존 개인정보 가림과 근거 검증은 그대로 적용한다.
