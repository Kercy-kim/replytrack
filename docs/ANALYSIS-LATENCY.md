# 등록·새 답변 분석 응답 시간 개선

2026-11-15. 기준 main은 `d2c5b59df3d99a445565f63b0d91fca3e663f3d3`이다. 같은 모델 `gpt-5-mini-2025-08-07`, 같은 가상 상담·정답·채점기로 전후를 실제 API에서 실행했다. 원문은 줄이지 않았다.

## 병목과 변경

작은 상담에도 전체 분석의 첫 생성부터 medium 추론을 사용했다. 기준 평가의 출력 81,340토큰 중 65,728토큰이 추론이었다. 첫 생성은 low로 줄이되, 이메일이거나 agent 원문에 정정·변경·철회·조건·예외 신호가 있거나 8개 메시지 또는 8,000자를 초과하면 medium을 유지한다. 분기는 계산량만 선택하며 질문 상태를 규칙으로 정하지 않는다. 수정·경계 검토·완료 통보 검토는 medium, 출력 한도 6,500토큰과 기존 시간 제한·검증·원문 보존은 유지한다.

모든 첫 분석을 low로 바꾼 첫 후보에는 다음 문제가 있었다.

- U03: 경계 검토가 부분 답변으로 고쳤지만, 최초 인용에 빠진 다른 기간 요금은 보완하지 못했다. 검토에서 필요한 근거도 반환하고 서버가 원문·발화자를 다시 검증하도록 수정했다.
- NS05: 명시적으로 정정한 배송 날짜를 상충으로 오판했다. 정정·철회 신호가 있는 대화는 기존 추론량을 유지한다.
- NU04: 발송 예정 기간을 받았는데 답변 대기로 남겼다. 행동 예정일 질문에 대한 답변과 행동의 실제 이행을 구분하는 지침을 명확히 했다.

잘못된 후보는 채택하지 않았다. [ADR 0020](adr/0020-analysis-latency.md)에 분기 기준과 검토 변경을 기록했다.

두 번째 후보는 48건을 통과했으나 추가 대비 Q03에서 묻지 않은 환불 절차를 요구했다. 조건·예외 안내는 medium을 유지하도록 보완했다. 이메일 웹 반복 검사에서는 low가 제출 자료 외의 서류를 임의로 부족하다고 판단하고 제목을 영어로 남겼다. 최초 이메일만 medium으로 유지해도 후속 low 분석에 완료 통보 검토가 추가되어 느려졌다. 따라서 **이메일 초기·후속 분석 모두 기존 medium을 유지하며 이메일 속도 개선은 성과로 주장하지 않는다.** 중간 실행도 원본 그대로 보존했다.

## 48건 전후 비교

배송·환불·구독 48건, 최초 분석 48회와 추가 답변 분석 7회를 실행했다. 동시 작업 수는 각각 최대 2개이며, 전후 실행은 겹치지 않았다. 시간에는 필요한 수정·추가 검토·저장을 포함한다. 이 표에는 텍스트 전사와 브라우저 화면 처리 시간은 포함하지 않는다. 중앙값은 정렬 후 `floor(n/2)`, p95는 nearest rank다.

최종 후보는 분석 55/55회, 질문 상태·근거 71/71회, 약속·기한 22/22회가 기대값과 일치했다. 미해결의 답변 완료 오판은 0/37회였다. [최종 비교](../evals/results/analysis-latency/comparison-final.json)와 [원문 대조 기록](../evals/results/analysis-latency/semantic-review-final.json)에 근거를 보존했다. 원문 대조는 개발 에이전트가 수행했으며 독립 사람 검수가 아니다. 일부 간접인용 어미가 어색한 문장까지 문체 품질을 인증하는 결과는 아니다.

원문 대조에서 NR02 설명에 복사된 `partial:` 접두사를 발견했다. 해당 상태 라벨만 제거하며 사실·숫자·인용문은 바꾸지 않는다. [55개 저장 결과의 표시 정리 재생 검사](../evals/results/analysis-latency/format-replay.json)에서 변경은 이 접두사 한 곳뿐이었다. 이후 이메일을 medium으로 유지한 변경은 쇼핑 55회 요청의 추론 설정을 바꾸지 않는다는 [분기 재생 검사](../evals/results/analysis-latency/routing-replay-final.json)로 확인했다. 표시 정리와 이메일 전용 보완 이후에 48건 전체를 새 API로 재실행했다고 주장하지 않는다.

medium에서도 영어 제목을 그대로 반환하는 이메일 사례가 있어 이메일 질문 제목에만 한국어 패턴·설명을 추가하고, 서버에서도 검사해 기존 한 번의 medium 수정 기회를 사용하도록 했다. 원문 인용은 번역하지 않고 일반 상담의 스키마에는 적용하지 않는다. 패턴 지원은 [공식 Structured Outputs 문서](https://developers.openai.com/api/docs/guides/structured-outputs)에 따른다. 패턴만으로 번역 의미 전체가 검증되는 것은 아니다.

[웹 비교 원본](../evals/results/analysis-latency/browser-comparison-final.json). 환불은 `browser-final-attempt.json`의 통과한 환불 사례이며 같은 실행의 이메일 최초 low 실패를 숨기지 않는다. 이메일은 이후 medium으로 유지한 `browser-email-final.json`의 핵심 흐름 전체 통과 결과다. 이메일 전용 분기는 환불에 적용되지 않는다. 최초 전사가 발화자 접두사를 남기는 경우와 제거하는 경우가 있어, 비교 시 앞의 `나:`·`고객센터:`만 제외해 동일 본문임을 확인했다. 원시 기록은 변경하지 않았다.

## 재현 및 범위

각 보고서에 소스 SHA-256, 모델, 호출별 추론량·usage·시간과 저장 결과를 보존했다. 기준 평가의 주요 제품 소스 해시는 원래 main과 일치한다. 평가가 진행되는 동안 다음 후보를 편집했지만 각 실행은 시작 시 불러온 모듈을 사용하며 새 후보는 새 프로세스에서 평가했다. 실패 후보를 덮어쓰거나 성공 사례만 합치지 않았다.

```powershell
node --env-file=.env scripts/evaluate-ai.mjs --suite full --analysis-only --model gpt-5-mini-2025-08-07 --out .artifacts/new-analysis-eval.json
node scripts/compare-evaluations.mjs evals/results/analysis-latency/baseline.json evals/results/analysis-latency/optimized.json
node scripts/check-live-browser.mjs --run
```

재현은 유료 API를 호출한다. 브라우저 검사는 설치된 Playwright·Chrome 경로를 환경변수로 설정한다. 평가 도구의 `--analysis-effort` 옵션은 첫 분석만 강제 변경하는 실험용이며 제품 설정이나 과거 코드 전체를 재현하는 기능은 아니다. 원래 제품과 웹 비교 시에는 기준 main의 격리된 작업 폴더를 사용했다.

이번 평가는 고정된 합성 상담 회귀 검사다. 미사용 자료 전체, 긴 이메일, 모든 표현의 정정·철회와 실제 사용자 품질에 일반화하지 않는다. 실제 사용자 데이터와 API 키는 결과 파일에 포함하지 않았다.
