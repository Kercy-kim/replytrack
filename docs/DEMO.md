# ReplyTrack 시연 안내

## 30초 예제 시연

서버를 실행하고 첫 화면에서 `예제 상담 열기`를 누릅니다. 화면에 “예제 상담 · AI API를 호출하지 않아요” 표시를 유지합니다.

| 시간 | 화면 조작 | 설명 |
| --- | --- | --- |
| 0~7초 | 질문 확인표의 세 카드와 원문 근거 클릭 | “한 번에 세 가지를 물었지만 수리 기간만 답변받았습니다. 수리비는 안내 대기, 배송비는 미답변입니다.” |
| 7~14초 | 재문의 · 인계 → 선택한 질문으로 초안 만들기 | “이미 답변받은 내용을 빼고, 남은 질문만 담아 다시 문의합니다.” |
| 14~21초 | 예제 답변 추가하기 → 이번 답변으로 달라진 점 | “배송비는 미답변에서 답변 받음으로, 견적 기한은 미정에서 날짜 확정으로 바뀌었습니다. 바뀐 항목만 원문과 함께 확인합니다.” |
| 21~30초 | 견적 도착 시연하기 → 직접 확인했어요 | “업체의 안내와 실제 수신 확인은 다릅니다. 직접 결과를 확인한 뒤 처리 상태를 마칩니다.” |

예제는 화면 흐름을 설명하기 위한 준비된 데이터입니다. 실제 생성형 AI 동작은 다음 순서로 별도 보여 줍니다.

## 실제 AI 시연

1. API 키를 서버 메모리나 로컬 `.env`로 설정합니다. 발표 화면에 키를 노출하지 않습니다.
2. `새 상담 시작하기`에서 아래 가상 대화를 붙여넣습니다.
3. `AI로 대화 읽기`를 눌러 인식 결과를 확인합니다. 발화자·원문을 수정할 수 있는 화면을 보여 줍니다.
4. `저장하고 질문 분석하기`를 누릅니다. 대기 화면 이후 질문별 근거와 상태를 확인합니다.
5. `재문의 · 인계`에서 초안을 생성하고 복사합니다.
6. `새 답변 / 질문 추가`로 후속 답변을 넣고 질문 상태·처리 약속을 확인합니다.

```text
나: 무선 청소기가 고장났습니다. 수리비는 얼마인가요? 입고 후 수리는 며칠 걸리나요? 왕복 배송비는 누가 부담하나요?
고객센터: 입고 후 수리는 3~5영업일 정도 소요되며, 수리비는 점검 후 안내하겠습니다.
```

후속 답변:

```text
왕복 배송비는 업체에서 부담하며, 내일까지 견적을 안내하겠습니다.
```

`내일까지`를 날짜로 보여 주려면 **실제 상담 날짜**를 입력합니다. 날짜를 입력하지 않으면 기한 미정으로 남는 것이 정상입니다. 실제 API는 응답 시간이 일정하지 않으므로 발표 직전에 한 번 실행하고, 대기 시간을 포함해 시연 길이를 조정합니다.

## 추가로 보여 줄 수 있는 차별점

- 상담 전체 보기 → 제목·업체 검색, 남은 질문·기한 확인 필터로 다음 할 일을 찾습니다.
- 초안을 편집하고 `편집 저장` → 새로고침 → `재문의 · 인계`에서 저장한 문장이 남아 있는 것을 보여 줍니다. 편집 전 생성 결과도 펼쳐 볼 수 있습니다.
- `상담 관리` → 보관함으로 이동 → 홈의 보관함에서 열고 복원합니다. 질문·약속 상태는 바뀌지 않습니다.

편집한 초안이 있는 상태에서 새 답변 추가·질문 상태 수정 등으로 넘어가면 초안 초기화 안내가 나옵니다. 필요한 문장을 복사하거나 내려받은 다음 진행합니다.

- 질문 판정을 직접 수정한 후 새 답변 추가 → 사용자 수정은 유지되고 새 AI 제안은 별도로 표시됩니다.
- 업체의 “안내 완료” 답변 → 사용자가 실제로 확인하기 전까지 처리 확인 필요로 남습니다.
- 변경 이력 → `반영 전후 비교 보기`를 펼쳐 이전 답변의 질문 상태와 약속 변경을 다시 확인합니다. 최신 비교와 과거 비교는 각각의 분석 당시 기록입니다.
- 모바일 원문/확인표 전환 → 작은 화면에서도 근거를 읽을 수 있습니다.
- 캡처 업로드 → 이미지 인식 결과를 저장 전에 확인·수정합니다.
