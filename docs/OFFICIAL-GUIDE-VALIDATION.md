## 검증 경계

초기 구현은 모의 AI로 검증했고, 이후 사용자가 제공한 키로 실제 `gpt-5-mini` 연결과 기본 사례를 점검했다. 키는 Git에서 제외된 로컬 `.env`에만 보관한다. 자동·브라우저 테스트의 모의 응답과 소수 실제 사례 점검은 전체 AI 품질 점수나 실제 사용자 평가가 아니다. 기간 초과·특수 상품·상충 입력·악성 지시 등으로 정답과 조건 누락을 추가 평가해야 한다.

FAQ 검색은 첫 검색 페이지의 제한된 결과를 사용하며 전체 상품 정책을 보장하지 않는다. 생성형 AI 의미 검토도 오판할 수 있으므로 공식 원문과 상품별 조건 확인이 필요하다. 실제 주문 조회, 로그인, 신청 실행은 포함하지 않는다.
