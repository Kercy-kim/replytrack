# 비회원 이용

2026-11-17. 비회원 기능의 구현과 로컬 검증 기록입니다. 운영 배포와 실제 사이트 점검 결과는 이 변경의 GitHub PR에 별도로 기록합니다.

## 사용 흐름

- 첫 화면에서 `가입 없이 시작하기`를 누르면 별도 비회원 세션으로 시작합니다. 로그인 폼의 아이디·비밀번호를 채울 필요가 없습니다.
- 등록·마스킹·AI 분석·한국어 설명·재문의·새 답변·기록 관리 흐름은 기존 회원 기능을 사용합니다. AI 프롬프트와 모델 설정은 변경하지 않았습니다.
- 상단 `비회원`에서 만료 시각을 확인하고 `계정에 기록 보관하기`로 회원가입 또는 로그인할 수 있습니다. 가입하면 같은 기록 소유권을 유지하고 기존 계정 로그인은 문의·사용량을 합칩니다. 합계 30개 초과·잘못된 비밀번호·가입 실패에는 비회원 기록과 세션을 유지합니다.
- 비회원은 시작 후 7일간 같은 브라우저의 HttpOnly 세션 쿠키로 접근합니다. 쿠키 삭제 시 복구할 수 없으며 공용 PC에서는 `기록 삭제하고 종료`를 사용합니다. 종료 전 확인을 거칩니다.

## 구현과 보관 범위

PostgreSQL `rt_users`에 guest 역할과 `guest_expires_at`을 추가합니다. 기존 관리자·회원·문의는 유지합니다. 임의의 클라이언트 소유자 ID를 신뢰하지 않고 서버 발급 난수 세션으로 사용자와 작업을 분리합니다. 관리자 설정·예제 생성은 비회원에게 허용하지 않습니다. Origin 검증과 세션 정책, 문의 30개 및 동시 작업 제한을 유지합니다. 새 비회원 생성은 서버 전체 10분당 100회로 제한합니다. 회원가입 10명 제한과 분리되어 있습니다.

만료 시 즉시 접근을 차단합니다. 데이터 정리는 서버 시작·새 비회원 시작·매시간 실행하며 비회원 문의·사용량·작업 예약·세션을 함께 삭제합니다. 서버 중단 중에는 다음 시작 시 정리합니다. 이 정리는 운영 DB 백업까지 삭제하는 기능은 아닙니다.

## 검증

- `node --test`: **288개 통과**, 실패 0. 비회원 3개 통합 테스트에는 격리·API 권한·CSRF·7일 만료·정리·재시작·정회원 정원과 분리·가입 전환·기존 계정 병합·30개 초과 시 원상 유지·동시 가입 충돌을 포함합니다.
- `node scripts/check.mjs`: JavaScript 문법 검사 통과.
- `node scripts/check-guest-access.mjs`: 실제 Chrome에서 빈 로그인 폼으로 비회원 시작, 이메일 등록·분석·영어 재문의·새 답변 비교, 새로고침, 다른 브라우저 세션 격리, 회원가입 보존, 기존 계정 로그인 병합, 종료, 1440px/390px 화면을 확인했습니다.
- AI 응답은 결정적 테스트 fixture입니다. 유료 OpenAI API 호출이나 새 AI 품질 평가를 수행한 결과로 해석하지 않습니다. 브라우저 캡처와 실행 로그는 `.artifacts/guest-access/`에 생성합니다.

기존 PostgreSQL API·로그인·가입·AI 평가 관련 회귀 테스트도 함께 통과했습니다. 운영 배포와 실제 사용자 효과 검증은 별도입니다.
