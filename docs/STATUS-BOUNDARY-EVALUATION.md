## 명확히 한 기준

| 상태 | 기준 | 남았던 사례에 적용 |
| --- | --- | --- |
| 미답변 | 해당 질문과 관련된 안내 자체가 없다. 무응답·인사뿐·무관한 문제의 안내 포함 | 답변 근거를 만들지 않음 |
| 부분 답변 | 관련된 실질적 방법·조건·일부 정보는 있지만 원하는 개별 결과나 전체 범위가 빠져 있다 | U02: 해지 여부 대신 해지 방법 안내 → 부분 답변, 방법 안내 인용 유지 |
| 확인 필요 | 관련 응답은 있으나 실질 정보 없이 미정이라고 하거나, 모호함·충돌·근거 검증 실패로 직접 확인이 필요하다 | R07: 환불액 정보가 아직 없다는 안내 → 확인 필요, 정보 미정 문장 인용 유지 |

명시적 향후 안내 약속이 있으면 답변 대기를 우선한다. 최신 정정으로 해소되지 않은 충돌은 확인 필요다. 요구한 정보가 모두 제공된 경우에만 답변 받음이다. 같은 상담 안에 있다고 다른 질문의 답변을 자동으로 재사용하지 않으며, 관련 정보와 미정 설명이 함께 있으면 제공된 부분 정보를 누락하지 않는다.

전체 판정 순서와 반례는 [ADR 0006](adr/0006-question-status-boundaries.md)에 정리했다. 서버는 미답변 판정에 답변 근거가 동시에 포함되는 모순을 확인 필요로 낮추되 근거·수동 상태·변경 이력을 보존한다. 특정 평가 ID나 특정 단어로 상태를 강제하는 방식은 사용하지 않는다. 기존 저장 기록은 다음 분석에서 새 기준을 적용한다.

## 반복 확인과 회귀

최종 프롬프트에서 R07/U02를 전체 평가 1회와 별도 반복 2회로 확인했다. **두 사례 × 3회 = 6/6회** 상태와 근거가 일치했다. 마지막 반복에서는 실제 U02 재문의도 생성·검토했고, 이미 안내받은 해지 방법을 반복해서 묻지 않고 현재 구독 상태를 문의하는 초안을 확인했다.

첫 수정 실행은 두 목표 사례를 통과했지만, R02에서 반품비를 환불액의 부분 정보로 잘못 연결하고 U03에서 일부 요금 정보와 미정 설명을 함께 처리하지 못해 26/28건이었다. 개별 질문의 관련 범위와 부분 정보의 우선순위를 보완한 뒤 전체를 다시 실행했다. 이 실패 결과도 삭제하거나 통과로 재채점하지 않았다.
