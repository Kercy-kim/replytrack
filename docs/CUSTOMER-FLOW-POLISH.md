# 사용자 흐름·문구 마무리 점검

2026-11-16, main 2c5d9f5에서 시작했다. 실제 Chrome과 OpenAI API로 합성 환불 문의와 영어 계정 복구 문의를 등록하고 새 답변·재문의까지 확인했다. 사용자 저장 데이터나 실제 이메일 계정은 사용하지 않았다.

## 발견하고 개선한 내용

1. 기본 화면에 모델명·토큰 수·API 키 점검 표현이 노출됐다. 연결 상태는 ‘AI 연결됨’ 등으로 표시하고 모델·사용량은 접힌 ‘분석 상세’로 옮겼다. 원문 확인 안내와 마지막 분석 시각은 유지한다. 키·모델 설정과 비용 안내는 연결 설정에서 확인할 수 있다.
2. 이미 연결을 확인했는데도 등록 단계마다 설정 안내가 반복됐다. 연결 확인 완료 시 반복 안내를 생략하며, 미설정·실패 상태의 설정 경로와 입력 보존은 유지한다.
3. 새 답변 뒤 ‘다시 확인’ 버튼으로 무엇이 달라지는지 모호했다. ‘새 답변까지 설명 업데이트’, ‘새 답변으로 할 일 업데이트’로 변경했다. 이전 결과 표시와 직접 완료 확인은 유지한다. 문의 제목·문의처·보낸 사람 등 입력 문구도 정리했다.
4. 긴 문의 하단의 재문의 바로가기가 답장 영역으로 키보드 초점을 옮기지 않았다. 전체 재문의와 개별 질문 재문의 모두 작성 영역으로 스크롤·초점을 이동한다. 개별 질문 선택과 작성 중인 내용은 유지한다. 수정 전 모바일 키보드 검사에서 재현했고 수정 후 통과했다.

## 검증

- 자동 테스트 **275개**, JavaScript 문법 **142개 파일**, Chrome 회귀 **9종** 통과.
- 실제 API 두 문의 모두 등록·분석 → 새 답변 반영·원문/상태/약속 비교 → 남은 질문 초안 → 편집·저장·복사·재접속을 통과했다.
- 영어 문의는 초기 한국어 설명·할 일 생성에 더해, 새 답변 뒤 두 업데이트 버튼을 실제로 눌러 갱신했다. 거래 ID 수신을 반영하면서 계정 복구·사용자 직접 수행을 자동 완료하지 않는지도 확인했다.
- 이미 받은 환불 금액·결제수단, 서류·심사 기간을 다시 묻지 않고 남은 질문만 초안에 포함했다. 질문 ID·원문 근거와 진행 요약도 일치했다.
- 모델·사용량은 기본 화면에서 숨기고 펼쳤을 때 확인 가능했다. 연결 완료 뒤 입력 화면의 반복 설정 안내가 사라졌으며 설정·연결 실패·취소·입력 보존도 로컬 회귀로 확인했다.
- 데스크톱·390px 실제 결과와 재문의 이동 화면을 확인했다. 로컬 검사는 320~1440px와 28px 글자 확대, 원문 왕복·키보드 초점·수정 초안 보존을 포함한다.

첫 수정 후 검사는 짧은 답장 양식이 문서 끝에서 화면 전체에 보이는데도 상단 150px 이내가 아니라는 이유로 중단됐다. 실제 화면을 확인하고 ‘상단 이동 또는 양식 전체 표시’로 검사만 수정했다. 중단 기록과 최종 재실행을 별도로 보존했으며 AI 출력이나 판정 기준을 바꾸지 않았다.
