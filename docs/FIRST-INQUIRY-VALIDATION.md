# 처음 문의하기 검증

검증일: 2026-11-17

## 동작과 범위

- 업체명·문의하고 싶은 내용·기록할 채널·한국어/영어를 입력한다.
- 공식 도움말·정책의 본문을 읽고 문의 경로, 최대 3개 절차와 준비물, 필요한 확인 질문 최대 2개와 첫 문의 초안을 만든다. 실제 인용과 출처, 적용 조건, 사용자 사실·초안의 일치 여부를 검토한다.
- 출처를 확인하지 못하면 해당 안내를 생략한다. 준비물이 표시되지 않는다고 해서 필요한 자료가 없다는 뜻은 아니다. 자가 해결 페이지와 상담원 접수를 구분하며 모든 사이트의 접수 경로를 보장하지 않는다.
- 준비 결과와 편집한 초안은 서버에 저장한다. `firstInquiry.state=preparing`에서는 메시지가 0개이고 질문 분석·답변 추가가 차단된다. 목록에서도 문의 준비 중으로 표시한다.
- 조건을 추가해 다시 준비하면 같은 ID를 갱신한다. 버전 충돌·취소·검토 실패는 기존 기록을 덮어쓰지 않는다.
- 사용자가 실제로 보낸 텍스트를 확인하면 그 내용만 고객 메시지로 저장한다. 생성 안내·준비물은 업체 답변으로 사용하지 않는다. 같은 문의 ID로 분석·새 답변·재문의가 이어진다.
- 첫 문의 초안은 직접 편집·복사한다. 자동 발송·실제 메일 수신 연동은 없다. 테스트의 전송 확인과 받은 답변은 가상 데이터이며 업체에 메시지를 발송하지 않았다.

## 발견하고 수정한 문제

1. Google 비밀번호 분실 안내에 사용자 이름 분실 절차의 전체 이름·복구 이메일 준비물이 섞였다. 해당 공식 문서의 실제 절을 분리해 비밀번호 분실 절차와 공통 예외·보안 안내만 제공한다. 문서 구조를 인식하지 못하면 해당 근거를 생략한다. 잘라낸 절의 요구사항은 인용 검증을 통과할 수 없다.
2. 검토 설명이 길어져 응답이 미완료되는 경우가 있었다. 피드백을 350자로 제한하고 검토 응답 예산을 확보했다. 실패 원인에 필요한 수정만 요청한다.
3. 정확하지 않은 인용 하나 때문에 초안 전체가 실패했다. 확인 불가능한 안내 항목을 제외한 뒤 나머지 결과를 검토한다. 인용을 임의로 고쳐 통과시키지 않는다. 절을 붙인 뒤에도 최초 원문에서 연속된 인용인지 검사한다.
4. 입력 문장 전체가 제목으로 표시되어 모바일에서 길었다. 간결한 한국어 제목을 생성하고 모바일에 초안 바로가기를 추가했다.
5. 추가 조건을 입력하고 창을 닫았다가 다시 열면 입력이 초기화됐다. 같은 문의의 입력을 유지하도록 수정했고, 조건과 영어 선택의 복원 테스트가 통과했다. 별도 UI 검토에서 해당 수정 완료를 확인했다.

## 실제 API 평가

수정한 부분을 재평가한 결과다. 한 번의 일괄 실행 결과로 표현하지 않는다.

| 사례 | 최종 확인 | 시간 | 로컬 결과 |
|---|---|---:|---|
| Google 비밀번호 분실 | 공식 복구 경로, 다른 상황의 준비물 제외, 한국어 초안 | 45.5초 | `.artifacts/first-inquiry-eval-google-v4/result.json` |
| Netflix 직접 결제·해지 후 청구 | 공식 고객지원 경로, 영어 첫 문의 초안 | 93.8초 | `.artifacts/first-inquiry-eval-netflix-v5/result.json` |
| 식별 불가 업체 | 공식 경로를 만들지 않고 추가 확인 질문·초안 제공 | 36.5초 | `.artifacts/first-inquiry-eval-v3/result.json` 마지막 사례 |

초기 실행에서 실패한 Google·Netflix 결과도 남겨 두었다. 실제 검색·모델 결과는 바뀔 수 있고, 조건이 복잡하거나 재검토하면 1분 이상 걸릴 수 있다. 임의의 전체 사이트 정확도나 사용자 만족도로 해석하지 않는다.

## 자동 검사

전체 테스트 307개 통과, JavaScript 161개 구문 검사 통과. 신규 검사는 미전송 기록 분리, 초안 저장·개인정보 마스킹, 전송 확인의 중복·버전 충돌, 동일 기록 재생성, 검토 실패 시 무저장, 조회 실패, 취소 후 쓰기 방지, 상황별 문서 분리와 정확한 원문 인용을 다룬다. 기존 48건 AI 품질을 전부 재실행한 것은 아니며 기존 분석 프롬프트는 변경하지 않았다.
