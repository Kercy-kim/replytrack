# ReplyTrack 2주 평가 운영

## 접속과 계정

- 서비스: https://replytrack.onrender.com
- 발표 결과: https://replytrack.onrender.com/presentation
- 관리자: `replytrack`. 기존 Render `REPLYTRACK_DEMO_PASSWORD`로 처음 한 번 생성한다. 이 비밀번호를 참여자에게 공유하지 않는다.
- 관리자는 우측 상단 계정 버튼 → **참여자 초대 코드 만들기** → 복사 후 한 사람에게 전달한다.
- 참여자는 로그인 화면의 **초대 코드로 처음 시작하기**에서 코드·아이디·12자 이상 비밀번호를 입력한다. 이메일 주소·전화번호는 받지 않는다.
- 참여자 10명과 관리자 1명을 지원한다. 초대 코드는 14일 유효하며 한 번만 사용된다. 참여자와 미사용 코드를 합쳐 10개까지만 발급하므로, 발급할 때 바로 안전한 곳에 복사한다.
- 문의·초안·약속·할 일·변경 이력과 AI 작업 조회/취소는 로그인 계정별로 분리한다. 관리자 화면에서도 다른 사람의 문의는 볼 수 없다. DB 운영자의 저장소 접근 권한과는 별개다.
- 세션은 7일간 유지된다. 로그아웃하면 해당 세션과 진행 작업을 종료한다. 공용 PC에서는 비밀번호를 저장하지 않고 사용 후 로그아웃한다.

## Render 설정

웹 서비스는 기존 `replytrack`, Node, Singapore, Free를 유지한다. Build `npm ci --omit=dev`, Start `npm start`, Health `/api/health`. DB도 Singapore, PostgreSQL, Free, 1GB로 만든다. 기존 수동 서비스가 있으므로 Blueprint를 중복 생성하지 않는다.

| 환경변수 | 값 |
| --- | --- |
| `OPENAI_API_KEY` | 기존 OpenAI API 키 |
| `OPENAI_MODEL` | `gpt-5-mini` |
| `REPLYTRACK_DEMO_PASSWORD` | 기존 16자 이상 비밀번호. 관리자 최초 생성 시만 사용 |
| `DATABASE_URL` | 같은 지역 PostgreSQL의 **Internal Database URL** |

Render가 `RENDER_EXTERNAL_URL`을 제공한다. 다른 호스팅에서만 `REPLYTRACK_PUBLIC_ORIGIN=https://정확한주소`를 설정한다. 키·비밀번호·DB 접속 문자열은 Environment에만 저장하고 Git·공개 문서에 넣지 않는다. DB 외부 접근은 연결 검증 후 비활성화하고 내부 네트워크 URL을 사용한다.

`DATABASE_URL`이 없으면 기존 로컬 SQLite 방식(공개 주소에서는 공유 Basic 인증)으로 동작한다. 계정 분리 운영에는 반드시 PostgreSQL을 연결한다. 기존 SQLite의 공유 기록은 새 계정으로 자동 이전하지 않으므로 필요한 기록은 전환 전에 내려받는다.

## 사용량과 동시 요청

- 계정별 문의 30개. 목록·원문·기존 결과 조회는 AI 작업 한도와 무관하다.
- 한국 시간 하루 AI 작업: 참여자 30회, 관리자 100회. 한 작업에 여러 모델 호출이 들어갈 수 있어 호출 수·토큰·금액 상한과 다르다. 시작한 작업은 실패·취소해도 포함한다.
- 개인정보 가림·OCR은 AI 횟수에서 제외한다. 공식 안내는 실제 시작 시 집계하며 기존 캐시나 적용되지 않는 사례는 제외한다.
- 계정별 진행 작업 1개. 전체 최대 2개 작업 실행, 실행·대기 합계 12개. 화면에 대기 상태를 표시한다. OCR은 메모리를 고려해 한 번에 하나만 실행한다.
- 서버 재시작은 진행 중 작업을 중단할 수 있다. 저장된 문의와 계정은 PostgreSQL에 남으며 재로그인 후 확인할 수 있다.

## 2주 운영과 종료

무료 웹 서비스는 15분 미사용 시 절전되며 다음 첫 접속은 지연될 수 있다. PostgreSQL 연결로 문의 보존과 웹 서버 절전은 분리된다. 발표나 평가 전에 사이트를 한 번 열어 둔다. [Render 무료 서비스 안내](https://render.com/docs/free).

무료 PostgreSQL은 생성 30일 뒤 만료하며 자동 백업을 제공하지 않는다. 이번 2주 평가가 끝나기 전에 각 사용자가 문의 상세의 **내려받기**로 기록을 보관한다. 이 파일은 읽기용 Markdown이며 자동 복원용 DB 백업이 아니다. 장기 보관·운영이 필요하면 만료 전에 DB 백업 또는 저장소 이전이 필요하다. OpenAI API 비용은 무료 호스팅과 별도다.

이번 DB 생성일은 **2026-11-17**, Render에 표시된 만료일은 **2026-12-17**이다. 2주 평가를 12월 1일 전후에 마치고 기록을 내려받는다.

배포 입력 원문·캡처는 Render 서버로 전송된다. 서버에서 전화번호·주소를 가린 뒤 사용자가 검토한 텍스트를 OpenAI에 전달한다. 자동 가림이 모든 개인정보를 탐지하지는 않는다.

이메일 인증·비밀번호 찾기·자동 메일 발송은 제공하지 않는다. 비밀번호는 안전하게 보관하며 분실하면 운영자 확인이 필요하다. 평가가 끝나도 DB는 즉시 자동 삭제하지 않는다. 운영 종료 시 사용자 기록 보관을 확인한 뒤 Render에서 종료한다.

## 검증

인증·계정별 접근·동시 요청·실제 API 결과는 [다중 사용자 검증](MULTIUSER-VALIDATION.md), 구조는 [ADR 0031](adr/0031-private-postgres-pilot.md)에 기록한다. 과거 Basic 인증 배포 검증은 ADR 0030에 남긴다. 최신 배포의 Live 상태와 DB 연결은 별도로 확인한다.
